# 性斗样本段落库（fight-examples）

配合 `fight.md` 使用。用在「两步走」的第二步：底本句子照抄、只换人物之后，润色时到这里找同类场景的样本原段落当示范。

**用法**
- 按场景找对应分类，看样本**怎么写**：比质地、受力形变、一来一回、嘴硬对照、胜者羞辱、败者残局、旁观者一笔。只学写法，不照搬内容。
- 出处写成〔篇名 L行号〕，行号对应 `novel-samples/` 下原文件。
- 摘录一字不改；中间删掉的部分标「……」。删去的有两种：①国族羞辱的词（本书禁用）；②袜子规格、鞋码之类的数字。
- 样本里还有的东西也**不照搬**：厘米、斤数之类的精确数字（罩杯字母、时长可以写）；扶她和男女对战的情节（本书没有）；「本钱」（全书不用）；「阴精」（本书掉的是阴珠，写实、不出系统提示）。
- 篇名简称：中美＝《中美爱情战》；复仇＝《中美爱情战：复仇》；中日＝中日熟女夺情记；间谍＝间谍过家家：新；龙腾＝龙腾凤鸣争高下；数码＝数码宝贝1 2。

**样本腔要点（对比底本腔）**
- 用词直白：直接、狠狠、使劲、猛地、一把、硬生生；部位直接叫（乳房、奶子、乳头、乳晕、阴唇、小穴），不用「酥胸、玉乳、娇躯」这类雅称。
- 一个长句用逗号串起四五个动作，最后落在结果上（谁被推回去、谁的腿弯了）。
- 台词放前面，后面紧跟说话人和一串动作；叫声和骂声夹在动作中间，越到撑不住越断续。
- 一段三到五句，感叹句多。
- 骂人：老娘、骚货、贱人、废物、手下败将；骂着骂着会揭短、提条件。
- **不用节拍倒数**（「三！二！」「每骂一句顶一下」）。
