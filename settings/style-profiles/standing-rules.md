# 常驻规则卡（standing-rules）

> 建于 2026-10-06（作者同意的省 token 方案）。**写手、润色、审稿每章必读本卡**；每章提示词只写本章特有内容（底本、回合对应、本章避让、衔接），通用规则写「见常驻规则卡第 X 节」。
> **本卡是速查摘要**，从 `CLAUDE.md` 第三节、`notes/00-决策记录.md`、`unify.md`、`dialogue.md`、`fight.md`、`nonfight.md`、`writing-style.md`、`.claude/knowledge/anti-ai.md` 顶部「作者覆盖」、三张人物卡压缩而来。**冲突时以 `notes/00` 为准，其次以原卡为准**；原卡改了，本卡跟着改。

## 一、工作方式（流程铁律）

1. 修改意见先编号逐条列出，作者回 OK/NG，只执行 OK 项。**问题要少**：只问方向、设定、剧情走向；措辞、称呼、小细节 Claude 按建议直接定，汇报里一句带过。不追问人物动作的理由。
2. 只加作者批准的内容；诊断出问题只提方案。默认修改方向是删。冲突、不确定就停下来问，不自行取舍。
3. 不臆断延伸设定；原创提案标「原创提案」，规模克制。
4. **不规定字数**（除非作者对某章提要求）；不为凑字数加内容。
5. **性斗回合一律取材，不原创**：从 `start/`（含甲伊性忍帖、修仙）或 `sexfight-database/` 找结构相近的现成场，章纲注明「取材自 X 篇 Lxxx–Lyyy」并列回合对应；招式与攻防流程照搬，只换人物；要改的标【改】先问作者。收尾（胜者处置、胜败对话）也取材。
6. **两步走**：①写手照底本抄原文句子，只换人物、场景、称呼；底本人物的性格、外貌、身体与本书已定不符处一律按本书改（第十节）。②单独一轮润色，见第七节。
7. **招式名、名器名不照抄**：一律另起新名，动作照搬。
8. 每场性斗保持新鲜感：每场挑不同的样本段落和手法，同一手法不连着两场用；节拍倒数、「碾一下问一句」偶尔用，给死不认输的一方。
9. **代入人设写**：把自己当成场上的人物，台词与反应从她的出身、性格、处境出发，不写通用台词。
10. 输家掉出的阴珠怎么处置**不问作者**，照甲伊、修仙的做法（当场、当着对方面毁掉，可带一句诛心话；败者可求饶，胜者可假答应再毁），Claude 直接定，且每章换方式（见第十一节）。
11. anti-ai **只列问题、不直接改稿**；去 AI 味仍单独一轮。
12. **交付标记**：作者调完、归档的正文，开头一行 `[chapter:第X章 章节名]`，结尾一行 `[newpage]`；未交付的稿子不加。archives 只放定稿，中间稿移 `.agent/drafts/`。
13. 正文后的报告、自评归档时删；产出不写字数、不写自评。

## 二、内容红线（正文不得出现 / 必须遵守）

1. **「性斗女王」四字不进正文**，也不借人物之口给晓柒月贴这个标签（设定、章纲、提示词可用）。
2. **「本钱」全书不用**，换成身材、乳房、腰、臀、脚、阴户等具体词。
3. **精确数字不写**（身高、体重、厘米、度数、年龄）；罩杯字母、时长可写。不写「岁」。
4. **阴珠 / 阳精**（旧名本源核心、卵子、阴精作废）。掉阴珠**不出系统提示**，写实写它被逼出；**正文不盘算还剩几颗**，诛心话不报数字（作者：不要把阴珠看得太重）。系统提示【阴珠：x/5】只在初入时那一次。
5. 阴珠路径：卵巢 → 子宫壁 → 宫口 → 穴道 → 穴口，可省中间；阴珠会很慢地自然恢复；大多数情况被胜者当场毁掉，吸收条件严苛。
6. 晓柒月**只抽到魔镜**，没有任何天赋；**魅魔血脉已删**，正文不写体液催情（谁的水进了谁嘴里只是羞辱或湿）。魔镜、白雪、系统、大本营在剧情世界性斗章里不出现。
7. 数字使者、主神真相、白雪的去向：正文不提、不发展。
8. 晓柒月前史一律成年后；**任何未成年相关内容不写、不采用**（素材里涉未成年的样本已删，不用）。
9. 不用国籍、民族羞辱词；不写兽交。第一卷：不出现男性、不写孩子、不写毒、不写皇帝；不用「何莲」「王荣」；「永巷」一律写「冷宫」。
10. 不说书名，不说「规则怪谈」「诡异」「副本」「NPC」；称呼用试炼者、原住民、剧情世界、剧情人物、性币。
11. 这个世界女人不论是否怀孕都能出奶：可以写出奶，**不解释、不说破**。
12. **约战台词、比斗规矩不再重讲**（「比什么？」「老规矩，谁先软下去谁输。」已删过）；应战可以一句「行。」带过。
13. **第一个世界不写温情**：性斗只有敌意和羞辱。不夸对方好看、好闻、可爱，不欣赏对方的腿脚，不把比脚香当情趣，不和解、不佩服；打量对方身体只为比高下，打量完落到敌意上。被对方勾起情欲可以写，但要写成身体背叛自己、被对方看出来拿来嘲笑。（第 0 章序章例外，可留一点点。）
14. 比喻、总结句 **Claude 不主动删**，由作者判断；但**不新加格言式泛论**（「爱美之心人皆有之」类）。
15. 人物做事不需要理由：不替动作找来由、不替反派讲动机、不写「她明白了」「原来如此」「教训」。情绪标签、心理说明可以写（作者 2026-10-01 放宽）。
16. 不新增章纲以外的情节和招式；名器名、招式名不给本卷新起（赤焰乳、缠丝锁只记名，不为名字加情节）。

## 四、叙述与台词口径

> **★ 性斗对话铁律（作者 2026-10-06，本节最高优先）**
> 1. **粗俗、火药味足**：直接骂、直接放狠话、直说器官（屄、奶子、穴、阴蒂），不绕弯、不文雅、不说书面腔。以 `start/主角人设.txt` 的对骂为准：「骚婊子」「我会干烂你的屄」「小心别被我撞烂」「也不过如此啊」「不是很厉害吗」。**非性斗段不受此条影响。**
> 2. **称呼用现实里真会用的叫法**（dialogue.md 第 2 条）：骚婊子、贱人、骚货、皇后娘娘、拿身份出身作称呼，可以来回嚼；**不现编描述性标签**（「没输过的」「收手的」）。
> 3. **♥ 只用于撒娇、发媚、故意恶心对方**；狠话、脏话不挂 ♥，不挂在每句挑衅后面。

1. **叙述腔**：白话，接近现代口语。不写「X道：」「只见」「顿时」；说话人用「说」或直接接动作。不新加「色情」「养眼」「性感」类评语词。古代器物、时间照用（一炷香、时辰）。叙述者「毕竟……」每章最多一处。
2. **台词腔**：白话、说完整，不古风、不过分简约（「诺」→「是」，少用罢了、何妨）。嘴仗只往狠里改：反问改断言，试探改贬低。
3. **腔调跟人走**：晓柒月轻佻、爱撩、挑衅、嘴硬反呛、原话奉还；何贵人 / 何皇后粗、泼、狠，自称老娘，拿杀猪和出身说事；宋皇后名门轻蔑、嘴硬到底；香兰慢悠悠、阴柔嘲弄，句尾可带「呢、哦、呀」，「呵呵」轻笑；宫女市井粗口。
4. **称呼用现实里真会用的叫法**，可来回嚼（皇后娘娘、贱人、骚货、拿身份出身作称呼）；**不现编描述性标签**（「没输过的」「收手的」）。
5. **对骂招牌**（dialogue.md，润色时挑用、每场换）：嘴上从不闲着；比对式台词（拿同一部位比完就下结论）；挑衅 + 下条件；心里认输嘴上不认；胜者逼认输的重复一遍比一遍狠；台词越凶紧接着越写身体撑不住；偶尔一句短促爆发句。
6. **♥ / 💢**：♥ 只给撒娇、发媚、得意嘲弄、故意恶心对方，**狠话不挂、不挂在每句挑衅后**，一场一两处；💢 只给破功那一下，一场最多一两处。
7. **心里话**：性斗章用单引号 ‘ ’，短，接「XX心里想着」或直接接动作；只放敌意、不服、轻蔑、算计；**不写解释自己身体反应的心里话**；一场三五处以内。非性斗章晓柒月的吐槽**不加引号**，直接写进叙述。
8. **分段**：台词单独成段（可带说话人和紧跟的动作）；带内容的骂、问、狠话一段只放这一句，对方反应另起一段；纯叫声可夹在动作句中间。性斗段一段 1–4 句，**不超过约 250 字**，超了在换人、胜负换手处拆。
9. **叫声、拟声**：直接写出声音，不写「她发出一声呻吟」「传来一声闷响」。拖长主要靠重复字（啊啊啊、哦哦哦）；越撑不住越断（不、不行了；我……我是……）。拟声词带「！」（“啪！”），可单独成段。招式名在叙述里用引号带出，不单独成一段裸引号。
10. **视角**：性斗章镜头在双方之间切，双方内心都能进，一个自然段只进一个人；非性斗章只跟晓柒月。称呼以名字为主，少用他 / 她（两个女人缠在一起时尤其）。

## 五、标点（作者 2026-10-06）

- **冒号**：只留给系统提示【】和【阴珠：4/5】这类格式；其余不用。
- **分号**：能不用就不用。
- **破折号**：只在台词里（被打断、拖长），叙述里一个都不用；一句最多一两对。
- **波浪号 `~`**：只在台词里，表示声音软化、拖长；一个音节组一个，叠 `~~` 表示更软更长。
- **反斜杠**：一律删（`\~`、`\[` 还原成 `~`、`[`）。
- 省略号：台词断字断句可用，叙述少用。原书天赋名、道具名用「」，【】只留系统提示。

## 六、性斗写法硬约束（writing-style + fight）

1. 按项目分回合（脚、胸、下体、气味、手技……），每回合分出胜负，胜负落在看得见的身体结果上（先泄、被顶下榻、被压到认输、形状被撞扁），不能只写「占了上风」。
2. 高潮具体、有先后：谁先到、谁喷得凶、谁先瘫，后到的怎么借势压上去。
3. 僵持写过程：力量一点点被推过去，写身体位置的变化，不写度数和厘米。
4. 比质地不比尺寸：肉感更足 vs 弹性更好、饱满厚实 vs 单薄、颜色深浅；两人摆在一起比。
5. 拆部位、受力写形变、反应落到具体部位（脚趾蜷缩、大腿根痉挛、想夹又不敢夹）、力气流失写成看得见的变化（从用力碾压变成虚虚贴着）。
6. 嘴硬对照：劣势方台词越凶，紧接着越写她撑不住。
7. 胜者当场羞辱败者（踩、捏碎阴珠、拍脸、揭短、逼认输），败者嘴硬或崩溃；给败者留一个静止的残局特写。
8. 情绪主要落在身体反应上；动词要狠（顶、撞、砸、碾、夹、薅、踩、挤），长句用逗号串一连串动作，中间夹短促的叫声和骂声。
9. 只学写法不学剧情母题（情敌争夫、正宫小三）；样本的错别字、的地得混用、精确数字不继承。

## 七、润色一轮（正式一轮，作者 2026-10-05）

- 对照 `fight-examples.md`（只读目录与本章相关分类），三层加工：①换腔调词（底本腔 → 样本腔；与第三节词表冲突时以词表为准）；②按样本句法节奏重排；③加样本招牌写法（比质地、受力形变、一来一回见高下、嘴硬对照、气味、败者残局、胜者当场羞辱、骂战升级）。
- **招式顺序、攻防流程、胜负不动**；润色只加描写。产出「底本句 → 润色句」对照。
- 对话润色同样三层（换贴人物的说法 → 底本句法重排 → 加第四节第 5、6 条招牌）。
- 样本段落库每写一章增补一点（从 novel-samples 新样本摘）。

## 八、非性斗章（nonfight.md 摘要；性斗卡的句式数值不用于非性斗章）

1. 一句一段为主；叙述句写完整（一句讲清前因后果，逗号连两到四个分句，用因为、所以、可、却、说明写出逻辑），不切成碎句。
2. 单独成段的短句只给吐槽、反应（「晓柒月哽住了。」）、结论或警报。一个事实只说一遍，说完接推论或动作。
3. 吐槽：触发 → 吐槽句 → 反应句 → 零到三句展开 → 收回剧情；一章一到三处，一处一种手法；对准外面的东西（系统、规则、对方台词），不造对称俏皮句。比喻串一章最多一处。「好消息 / 坏消息」不再用。原作吐槽原句只在情境相同时照搬。
4. 情绪直说一句就走，不用盯着、没动、僵住这类定格暗示。
