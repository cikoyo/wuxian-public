# 非性斗章风格卡（学原作 1.txt）

> 2026-10-01 由 style-distiller 依据原作 `start/yuan/1.txt` 全文（10 章，去标题后 20679 字）蒸馏生成。本卡只管非性斗章；性斗段用 `fight.md`；两者都继承主卡 `writing-style.md`。
> 起因：第 2 章原创段落 AI 味重，作者点名的句子见下「原作不会出现的写法」。分析过程见 `settings/style-profiles/analysis/nonfight.md`。
> 称呼提醒：例句里的「诡异」「诡币」「副本」是原作原词，本书写作「原住民」「性币」「剧情世界」。

## 叙事身份

一个脑子转得快、嘴上不饶人的讲述者，贴着晓柒玥一个人讲：她看到什么、想到什么、推出什么，就平平实实地说出来。句子完整，逻辑写在明面上；情绪直说一句就走；笑点来自身份反差和对系统、规则的反问，点一下就回到剧情。不摆镜头，不做定格，不玩对称句。

## 硬约束（摘要，全文见 frontmatter hard_constraints）

1. 称呼替换：诡异→原住民，诡币→性币，副本→剧情世界，NPC→剧情人物。
2. 叙述写完整长句，一句讲清前因后果；不切碎。
3. 一段一件事；短句单独成段只给吐槽、反应、结论。
4. 一个事实只说一遍，说完接推论或动作。
5. 吐槽顺序：触发 → 吐槽句 → 反应句 → 展开 → 收回剧情；一处一种手法；一章一到三处；对准外面的东西。
6. 比喻串一章最多一处，三项，日常，递进，最后一项最具体。
7. 口语自嘲是点缀，一句一个。
8. 情绪直说，接动作或推理；不用定格暗示。
9. 系统提示只交代一句怎么来，不描写文字浮现；弹完接吐槽或推理。
10. 规则引用：「XX守则几。」→【原文】→ 推理。
11. 看完文字并进下一件事，不写阅读过程。
12. 数东西一句说完数量和意思。
13. 回忆用完整陈述句直说，不写谜语句。
14. 对话一人一段，台词后跟一句交代因果。
15. 视角只跟晓柒玥，揭秘写成她的推断。
16. 精确数字照主卡；未成年相关段落不采用。

## 描写层次和手法

### 1. 叙述句怎么组织

- **句长**：叙述句（不含对话、系统文本）平均约 34 字；21 字以上的句子占七成多，8 字以下只占 7% 左右。整体（含对话）平均约 29 字。句子是「完整一句」，不是「碎片」。
- **一句的内部结构**：主语 + 两到四个分句，常见三种骨架：
  - 场景 + 动作 + 心理落点：「时肆举着伞站在雨中，抬头看向办公楼，心下了然。」（L42）
  - 事实 + 转折 + 结论：「规则强调他很热情，而不是善良，虽然这两个词听着都像是有积极正能量的褒义词，可放在规则怪谈里就完全是两个意思。」（L175）
  - 动作链带目的：「时肆从沙发上站起，看了一眼正蜷缩在狗笼瑟瑟发抖的黑狗，趁它还没狗叫的功夫飞快溜进第一间房。」（L245）——每个动作都在推进位置或带目的，不写「看完，记住了」这种原地踏步的动作。
- **段落**：原作几乎一句一段（全文单句段约 85%，叙述段约 99%），段落平均三十来字；超过八十字的段落全书只有十来段，多是推理或背景交代。
- **单句段的短句用在哪**：只有三类——吐槽（「……就这？」L59、「这还用你说？」L94、「不该回来不早说？」L598）、反应（「时肆哽住了。」L60）、结论或警报（「一切只能靠自己。」L67、「有人在跟踪她！」L134、「只是护食。」L332、「逍遥法外的人太多了。」L375）。倒计时也单起一行（L40「距离怪谈降临还有两分钟。」）。
- **从动作到心理的过渡**：
  - 「想到这儿，……」「正这么想着，……」「不提这茬，……」（L21、L54、L180、L46、L50）——用一个短引子把刚才的推理收住，接情绪或下一个动作。
  - 同一句里动作在前、心理落点在后（L42「……抬头看向办公楼，心下了然。」L234「时肆默默看着一切，心中疑虑更深。」）。
  - 外部信息 → 直说情绪 → 对号入座 → 自问（L363–365）。

### 2. 吐槽的写法

- **位置**：紧跟触发物——系统提示（L59、L94）、对方台词（L110「不是，这台词硬往下说啊？」）、短信（L598）、自己看到的荒唐东西（L211「“……”时肆无语地将视线挪开。」）。
- **密度**：全文约十一二处，平均两千字一处，约每章一到两处。第 1 章开头（L16–17、L59–67）最密，进入剧情后变稀，靠推理推进。
- **句式**：
  - 反问：「系统抽取天赋的时候都不做背景调查的吗？」（L61）「坐车不掏钱，不就等于吃霸王餐吗？」（L562）
  - 半句话：「……就这？」（L59）「等等，两道影子？」（L130）「不是，」开头（L110）
  - 定论句：「马后炮也没她这么玩的。」（L600）
  - 好消息 / 坏消息：全文只用一次（L16–17），两半说的是两件不同的事（看过这本书 / 只看了开头），后半句是自曝短处，后面紧跟三大段交代（L18–20）。不要把同一件事正说反说凑成一对。
- **网络口语与自嘲的分寸**：口语词嵌在正常叙述句里（「社畜打工人」L11、「把书养肥」L17、「吃灰」L18、「开挂和拥有金手指」L53、「狗屁技能」L66、「两脚羊」L177、「兜比脸还干净」L563），一句一个；自嘲落在身份上（「炮灰路人甲」L12、「只能硬生生作惹诡异厌恶的真言者」L144、「急得只想扇自己嘴巴子」L116）。
- **比喻串**：全文只一处（L63），三项，日常，最后一项最具体（倒扣十块）。紧跟着就用两句正经推理把它落地（L64–65），再用一个俗语反转（L66 罗马 / 贫民窟）收住。
- **收回剧情**：吐槽后必有一句把人拉回来——「一切只能靠自己。」（L67）「吐槽归吐槽，时肆还是继续看消息。」（L601）

### 3. 情绪、心理怎么写

- 以直说为主：「时肆的心沉入谷底」（L7）、「她有些心烦意乱」（L21）、「时肆感到疑虑，但还是按下了拨通键」（L27）、「突然对自己抽取的天赋有些期待」（L54）、「魔镜真言的力量让时肆恐惧」（L190）、「心下一紧」（L363）。
- 身体反应只用一个短语，而且马上接动作：「时肆脊背发凉，连忙去抓后车座门把手。」（L384）「冰冷的声音吓得时肆身体一颤，转头望去……」（L305）
- 动作来由直接写：「时肆庆幸刚才小女孩没有向她提问，不然……」（L124）「于是想到了用打断对方提问的方式，阻止天赋启动。」（L191）
- 心理的主体是**推理**：原作大量篇幅是主人公把线索串起来（L175–179、L237–241、L284–289、L437–446），用「说明」「意味着」「难不成」「究竟」「极有可能」推进。

### 4. 系统提示、规则文本与叙述的衔接

- 来：一句交代来源（提示音、叮、手机震）→ 提示原文逐行【】。
- 走：提示结束，下一行直接是吐槽、背景解释（L50「不提这茬，时肆差点忘了，原书中……」）或下一件事（L585）。不写字的样子、不写盯着看。
- 规则再现：「XX守则几。」单行 → 规则原文单行 → 推理（L131–134、L146–148、L235–241、L308–310、L394–398、L467–470、L520–524、L550–559）。
- 规则全文列完后，一句把「读完」并进事件（L90 手机黑屏、L615 再次黑屏）。

### 5. 对话

- 一人一段，台词短，常见「台词 + 叙述补一句为什么 / 结果」（L107、L114、L183、L306、L352）。
- 标签混用：「时肆点头，“嗯。”」（L349）「出租车司机来了兴致。」（L350）「时肆平静地说道：“清海村。”」（L529）
