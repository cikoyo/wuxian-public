# 全书统一卡

**为什么要这张卡**：性斗段是从不同底本抄句子、再按不同样本润色出来的，每章的叫法、腔调、分段都会跟着底本和样本跑。作者要求「作为同一篇文章，我们需要做文风统一」（2026-10-05）。

**和其他卡的分工**
- `writing-style.md`、`fight.md`：管性斗段**往六篇样本靠**（动作链、比质地、受力形变、胜者羞辱……）。
- `nonfight.md`：管非性斗段**往原作 1.txt 靠**。
- `fight-examples.md`：样本段落库 + 换词表（底本腔 → 样本腔）。
- **本卡**：只管**本书自己的口径**——同一样东西本书叫什么、叫声怎么写、谁叫谁什么、作者改稿时一贯删什么。上面几张卡已经写过的规则这里不重复，只在需要时一句指过去。
- **冲突时**：本卡词表与 `fight-examples.md` 换词表的「样本腔」目标词不一致的，以本卡为准（换词表管腔调，本卡管本书定下来的叫法）。本卡与 `notes/00` 冲突的，以 `notes/00` 为准。

**用在哪一步**：润色 agent 交稿后、放入 archives 前，按第三节清单过一遍；写手照底本抄句子时，就按第一节词表换叫法。

## 二、统一口径

### 1. 叙述腔
- 白话，接近现代口语。定稿里「X道：」「只见」「顿时」都是 0 次，不要加回来；说话人用「说」或直接接动作。
- 古代器物、时间照用：肚兜、亵裤、褥子、坐榻、殿砖、宫服、一炷香、时辰。现代度量不写（主卡已定，罩杯字母除外）。
- 网络口语的评语词（「色情」「养眼」「性感」「好色情」）只在第 5 章出现，第 2–4 章 0 次；以后**不新加**，第 5 章的去留见第四节 A9。

### 2. 台词腔
- 白话、说完整，不古风、不过分简约（作者第 3 章批注：「上位邀战，下位推不得」→「位分比您高的人邀您比斗，您不能拒绝」；「诺」→「是」）。
- 腔调跟人走，不统一成一种声音：
  - **何贵人**：屠户出身，泼、狠，拿出身反咬（「杀猪的手劲大」「我杀过的猪，叫得也这么硬」）。
  - **宋皇后**：名门轻蔑，揭对方出身，嘴硬到最后（「一个杀猪的……也配问我服不服？」）。
  - **女官**：阴柔嘲弄、不紧不慢，句尾可带「呢、哦、呀」（作者亲手改出「真是欲求不满呢」）。
  - **宫女**：市井粗口，老娘、臭骚屄。
  - **晓柒玥**：性斗女王，嘴上轻佻、爱撩、爱挑衅，嘴硬、反呛（「对，就是给你闻的」「放屁！」）；不写她温顺（2026-10-06 人设重做：删「骗子出身」，见 `character-setting/xiao-qiyue.md`）。
- 嘴仗只往狠里改：反问改断言，试探改贬低（见本节第 8 条作者改例）。

### 3. 呻吟、拟声格式
- 一个音节组后面跟**一个** ~，再接 ！：「“嗯\~！哈啊\~！”」「“啊啊\~！不、不行了\~！”」。**波浪号表示声音软化、拖长**（呻吟、撒娇、尾音），只出现在台词里。
- **可以叠 ~~**（多一个表示更软更长，作者 2026-10-06 示例）；拖长主要靠重复字（啊啊啊、哦哦哦、噢噢噢噢）。**破折号只在对话里用**（被打断、拖长），叙述里不用。
- **正文不留反斜杠**（作者 2026-10-06）：编辑器转义的 `\~`、`\[` 一律还原成 `~`、`[`。
- 越到撑不住越断：顿号断字（不、不行了）、省略号断句（我……我是……皇……）。
- 拟声词带标点：「“啪！”」「“砰！”」「“嘣！嘣！”」「“咕啾咕啾\~”」；可单独成段。
- 招式名在叙述里用引号带出（「这就是宋皇后压箱底的乳技，“泰山压顶”」），**不单独成一段裸引号**。

### 4. 心里话
- 性斗章：单引号‘’+「XX心里想着」或「她心里冷笑」再接动作（主卡已定）。定稿用量 2/1/3/1 处，一场 1–3 句就够。
- 心里话只放**敌意、不服、轻蔑、算计**（‘垂死挣扎罢了……’‘怎么回事……她怎么还不泄！’）。作者删过的类型：解释自己身体反应的（‘这身子……比我的脑子先有反应了。’）。
- 非性斗章：晓柒玥吐槽不加引号（nonfight 卡已定）。

### 5. 分段
- 台词单独成段（主卡已定）。本书补充两条口径：
  - **带内容的骂、问、狠话**：一段只放这一句，可以带说话人和紧跟的动作；**对方的反应另起一段**。
  - **纯叫声**（嗯\~、啊啊——）可以夹在动作句中间，这是样本写法，不算违规。
- 性斗段一段 1–4 句，**一段不超过约 250 字**；超过就在动作换人、或胜负换手的地方拆。定稿第 2、3 章平均每段约 45 字、第 5 章约 36 字，第 4 章约 76 字且有 5 段超过 300 字——以第 2、3 章为基准。
- **分号、冒号、破折号少用，且要落在合适的地方**（作者 2026-10-06）：分号能不用就不用；冒号只留给系统提示【】；破折号只在对话里。

### 6. 比喻、总结句
- 作者规则：比喻、总结句 **Claude 不主动删**，由作者判断（notes/00 2026-09-30）。「像 / 仿佛 / 如同」混用，不禁。
- 但作者第 5 章删掉了**格言式泛论**：「爱美之心人皆有之」「所谓食色性也，好色和性别是没有关系的」。这类给欣赏、动情找理由的格言，润色时**不新加**。
- 定稿里比喻密度差别大（「像」2/3/4/5 章：5/1/9/20），不追求一致；只是不要为了「样本腔」一场塞进太多。

### 7. 温情禁止（作者 2026-10-05）
第一个世界的性斗**不写温情、不写互相欣赏，双方只有敌意和羞辱**。落到写法上：
- 打量对方身体只为**比高下**，打量完必须落到敌意上（皱眉、不服、冷笑、挑衅）。第 5 章保留的样子：女官看晓柒玥下身「眉头不明显地皱了一下……很快又挂回了那副不紧不慢的笑」。
- **不写**：夸对方好看、好闻、可爱；欣赏对方的腿、脚；比谁的脚更香当成情趣；「娇哼有点可爱」「想跟她做点更多的事」；对方的气味写成好闻。
- **可以写**：被对方身体勾起情欲——但要写成身体背叛自己、被对方看出来、被对方拿来嘲笑（「你是不是还没动情呀？」）。情欲是输了一招的记号，不是好感。
- 收尾不写两人和解、互相佩服；胜者当场羞辱（踩、捏碎阴珠、拍脸、擦手扔肚兜），败者嘴硬或崩溃。
