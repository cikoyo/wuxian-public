## 必须写进提示词的要求

### 一、写法（nonfight 卡）
1. 一句一段为主；叙述句写完整长句（一句讲清前因后果）；单独成段的短句只给吐槽、反应、结论。
2. 吐槽不加引号直接写进叙述（触发→吐槽句→反应句→展开→收回剧情；一处一种手法；对准外面的东西）。
3. 系统提示（若有）只交代一句来源；看完文字不写阅读过程；不写碎句定格、动作三连拍。
4. 情绪直说一个短语，接推理或动作。
5. 对话一人一段，台词后跟一句交代因果；对白用 “ ”。

### 二、作者的去 AI 味口味（写进写法要求）
