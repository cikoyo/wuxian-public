# vol-1-ch-4 修改清单（round 2，来自 reader 不通过 + anti-ai 同意项）

**做法：在原稿上逐处小改，其余一字不动。** 不重写全章，不加新情节，不动招式名与攻防流程，不动照录台词与章末两句。改完后 `---` 后的「章纲外新增的细节」清单同步更新（删去随改动消失的条目）。

## A. 红线：掉阴珠段与第 2、3 章近同句（必改）
1. 「小腹深处一阵抽紧，一颗阴珠从子宫壁上脱落下来，滑过宫口，又沿着穴道往下走」→「宋皇后肚子里一阵往下坠，一颗阴珠松脱下来，顺着宫口往外挤，一路往下走」（后半句穴壁挽留不住保留）。
2. 「穴里一阵阵绞紧，大腿根抖个不停，穴口一张一缩地往外吐着淫水」→ 删「穴里一阵阵绞紧，」；「穴口一张一缩地往外吐着淫水」改「腿间一股股往外冒水」。
3. 「阴珠挤出穴口那一下，一股快感从下身直冲上来，宋皇后的身子猛地弓起」→「那颗阴珠一出穴口，宋皇后的身子猛地弓起」。
4. 「穴口跟着喷出一股浓稠的淫水」→「腿间又涌出一大股水」；「裹着一层水」删。

## B. 读感硬伤（必改）
