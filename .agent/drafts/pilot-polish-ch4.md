## 五、自查

**招式顺序、攻防流程、胜负**（对照底本江山美人传 L1446–L1474）
1. 邀战 → 宋皇后屏风后揉硬乳头 → 突然强吻、胸顶胸，宋占先手。
2. 十字点樱（十字磨乳头）→ 何贵人躲开乳头、用吻抢回主动 → 分开，互骂（宋：野丫头还有两下子；何：揭穿揉乳头）→ 脱衣，扑撞开场。
3. 盘坐对视比身材 → 何贵人抿嘴被宋皇后看见，宋大笑 → 何「最后一回笑得这么开心」→ 宋舔鼻尖 → 何强吻扑上 → 宋揉臀、膝顶阴户，何照样还击 → 宋略占上风，推开。
4. 宋坐上何的腿压胸（上位）→ 何挺乳奇袭、抱着一起倒下 →「从下往上掀翻」。
5. 火烧连营 → 夹肘比乳沟 → 宋乳头扎乳晕，何从下往上回扎吃亏 → 泰山压顶 → 巨灵开山化解，宋被掀翻压在下面。
6. 何抽打宋的乳房 → 宋用阴户往上撞，何没理会，下面泛滥、抽打变轻 → 滚开休息。
7. 磨穴：对坐顶穴 → 互骂 → 互灌不泄 → 倒在榻上磨几个时辰 → 宋先撑不住坐起 → 何挑衅 → 宋贴上去，越来越虚 → 宋先泄，何未泄 → 掉阴珠 → 何踩碎。

顺序、攻防、谁占上风、谁先垮、胜负全部未动。招式名十字点樱、火烧连营、泰山压顶、巨灵开山原样。

**禁用内容**
- 精确数字：没有新增（「四五步」「几十个回合」「几个时辰」「一炷香」是现稿原有的，属步数、时长）。
- 「本钱」：没有。
- 古风台词：「野女子」→「野丫头」「吻战」→「亲嘴」；新加台词都是白话。
