## 〇、Memo（一句话）

几个月后的一天，兰斯把「绑架王女、逼赛斯王出来对话」的任务塞到晓柒月手上；她劝了一通被打断，一问才知道王女是赛斯十大美女之一，人绑回来是进兰斯被窝的，她既挑不着、也攒不到进度，还要陪着担赛斯王报复的风险，于是拿牙疼请假、当着兰斯的面关了门。队里人都由着兰斯，只有熏去抗议过。第二天小队空手回来：熏在王女跟前拦人、和兰斯动手，被忍者打晕，兰斯回村就宣布熏是奸细、关进了牢房。晓柒月起先不打算管，理智告诉她不合适，可一想到熏抱她、咬她、背她回家那几下，鬼使神差地给自己找了几个理由，夜里还是摸进荒得长草的牢房，躲在走廊暗处，看见兰斯带着队里那个阴沉的魔物娘调教师洋葱站在熏的牢门前「拷问」；洋葱开口就是真刀真枪的法子，兰斯嫌「一点也不快乐」，自己瞎玩了一通，熏咬着牙一声不吭，兰斯赌气走了，洋葱收拾东西时说了句「那个人是兰斯真是太好了」。人都走了，她用铁丝捅开牢门，熏却不肯走，还拿她的原话「由于各种原因」回敬她；她从这句话推出来，熏是赛斯王派进冰炎的卧底，拦绑架是职责，不逃是因为兰斯根本没真怀疑她，一逃就坐实。话刚出口，熏的眼神越过她往后看，背后腾起一阵烟，后颈一痛，她眼前一黑。

## 二、情绪设计

- **情绪锚点**：被塞任务的无语 → 问出真相的了然（懒得劝了）→ 关门回家睡觉的痛快 → 听说熏被关的皱眉 → 算完账决定去的干脆 → 牢外看戏的冷静 → 撬锁成功的顺手 → 熏不走的莫名 → 想通卧底的一乐 → 后颈一痛、黑。
- **微弧线**：平（日常任务）→ 小起（王女任务、请假）→ 下沉（熏被关）→ 紧（夜探牢房）→ 小高点（推出卧底）→ 骤断（被打晕）。
- **章内冲突阶梯**（非性斗，轻）：①兰斯胡来，她劝不动 → ②熏拦人、被打晕、被扣奸细 → ③兰斯带着洋葱进了牢房 → ④门开了，熏不走 → ⑤她猜中了不该猜中的事 → ⑥身后有人。
- **信息差**：读者和晓柒月一起不知道熏为什么拦；兰斯的「拷问」读者先看到「他根本没当真」，熏那句回敬让晓柒月和读者同时想通；忍者从头到尾在暗处（晓柒月不知道，熏先看见）。

**采用知识库方法论（Claude 匹配，不问作者）**
- 冲突升级：连锁反应——王女任务 → 熏拦人 → 被关 → 夜探 → 撬门 → 被抓，每一步是上一步的后果；反转误导——前面一路按「兰斯冤枉熏」走，熏一句回敬翻成「熏真是卧底」。
- 情绪拉扯：信息差错位——她以为自己在救冤枉的人，其实熏比谁都清醒；节奏控速——前半请假、听消息走得快，后半夜探放慢。
- 钩子悬念：认知错位（熏不走）→ 一句话打开；章末用「话没说完就被打断」收，悬到第 23 章醒在洋葱那里。
- scene-craft：对话动作穿插（兰斯说话带昂头、大手一挥、嘎嘎笑，洋葱慢条斯理不带表情）；环境感官分层（牢房荒草、黑走廊、牢门里一盏灯、那阵烟）。
