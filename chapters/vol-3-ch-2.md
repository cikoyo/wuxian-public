## 一、动机链与因果链（正文要能逐条对上）

> 上一章兹鲁奇原定撂下的「明天在银行算账」已被作者删掉，终稿只剩「好，很好。你有种！」。本章的「去银行」「换家伙」「再打一场」都要靠下面几条自己立住。

### 1. 兹鲁奇

1. **为什么清早来拷问室拿影像石**：那块石头搁在拷问室架子上，屋里发生的事它都录着——昨晚也录着，包括她被一个 2 级贱民骑到喷珠、阴珠被当面摔碎。她要去银行一整天，不放心把这东西留在家里让下人碰（正文只写动作：放影像时前头一闪是那场性斗，她脸一沉，手指一拨跳过去）。
2. **为什么要把晓柒月带去银行**（L384「一会我要把她带到银行去」，在败露之前就说了）：①她白天必须在银行，等不到晚上；②「你有种」不是夸，是记仇——在性斗里丢的脸只能在性斗里找回来（上一章已立），她要今天就找；③银行办公室是她的地盘：墙里夹钢板、隔音，屋里立着她的 X 型刑架，抽屉里有她的家伙，没人进得来。
3. **败露后为什么更不能把人留在家里**：女仆背着她假打——家里的人靠不住了，人要放在自己眼皮底下。
4. **女仆的下场**：在兹鲁奇眼里，背叛她的 2 级「连被我碰的资格都没有」（L514 照用意思）——她不屑亲手罚，扒了女仆裙，把人交给男仆们，再丢给他们一块影像石，叫他们录下来（L516 的意思），男仆们嬉皮笑脸地把人推出去，门一关。后面的事正文不写，读者自己明白会很惨。女仆不再出场。（原著匕首逼杀、别针刺乳不明写；轮奸不写，只靠这句话和男仆的笑暗示。）
5. **为什么换双头龙**：①赤蟒昨晚被晓柒月夹脱，根部那圈小刺从肉里扯出来，伤还结着痂，今天戴不了；②她看明白了输在哪——赤蟒连着神经，快感会倒灌，又能被人从身上夹下来。双头龙不连神经，她拿自己常年玩惯、练得有力的穴夹住一头控制另一头（底本 L25 樱柳正是这个用法），「这回你夹不走了」。
6. **为什么输了不再跟她性斗、改用项圈**：连输两场，两场都输在身子上——再比下去只会再输，性斗里这口气找不回来了。她是主人，项圈是她给奴隶戴的，按一下就能让对方瘫软；既然比不过，就用主人的手段把人按在脚底下。**因果：晓柒月赢了性斗，失去反抗是因为项圈，不是因为输。**（呼应上一章：她输了就用魔法掐断。）
7. **为什么用穴夹着双头龙给她深喉**：她是虐待狂，爱听女人的惨叫和呛咳；用的还是刚才输掉的那根双头龙、还是自己夹着——要让对方嘴里含着她的东西、跪在她胯下，把刚才的脸一口口找回来。
8. **为什么放毒气、说出口令门**：照原著（L678–L684）。银行被劫，她在「天国的房间」设了毒气陷阱，隔着监视镜炫耀，顺口说出唯一的活路是一道只有长官以上才知道口令的门。她没想到 2 级市民里有人知道口令（L702）。

### 2. 晓柒月

1. **败露时为什么愤怒**：女仆冒着风险帮她假打，她是感激的；现在女仆因为她要遭殃。她喊出「要罚就冲我来，至少放过——」，被一道闪电截断（L412–L416 照用）。眼看女仆被扒了裙子、交给男仆、门关上，她**非常愤怒**——但受制于人，再开口只会多挨一道，于是把火压下去，没再出声。不写温情独白、不写愧疚，只写愤怒（攥紧的手、咬住的牙、盯着门）。
2. **被套麻袋时为什么不挣**：挣了也出不去，白耗力气；一会儿多半还有一场，这股火要留到那时候（一句心里话，不加引号）。
3. **为什么应「是，主人」**：1 级邀战，2 级不能拒；她也要打——兹鲁奇身上还有珠，每一颗都是进度，也是替女仆讨的。口头上照叫主人，但写出她是咬着牙应的、心里在烧。不急吼吼，不挑衅。
4. **为什么开局先扑上去又被翻**：照底本 L23–L24。兹鲁奇说「过来」以后她先扑，可诺薇这副身子力气小一截，被十指相扣翻了过来。
5. **为什么死命压着角度、不让双头龙往里走**：昨晚她摸清了这具身子宫口低、浅，一顶就酸。底本胡夷靠「子宫吊得高」挡（L34），她没有，只能拿腰和穴里的箍压着角度，让龙头贴着穴壁滑开、不正对宫口（【改】K5）。挡得住一阵，挡不久，所以先泄了一回。
6. **为什么叫得软、一口一个「主人好厉害」**：底本胡夷闭眼假装沉迷（L37）是卖破绽；本书改成她顺着「奴隶」的身份恭维着叫，叫得兹鲁奇以为她服了、乐得喊号子，没发现自己的阴唇正被一点点吸过去（L38）。表面恭敬、暗里使坏；**和上一章「叫得越响兹鲁奇越疯」的挑衅不同手法**。
7. **翻盘后为什么那么狠**：就是败露时压下去的那股火。逼珠时不留情、不给喘气，折叠、喷奶糊脸、嗦舌头堵嘴、一口气顶到底——每一下都带着火（写在动作和力道上，不写成心理独白）。
8. **为什么两颗都拿到办公桌上处置**：第一颗掉在地毯上，她顾不上，接着逼第二颗；两颗都出来后，她才起身拾起，走到办公桌前。她赢了不踩脸、不放狠话，照叫主人；可兹鲁奇是纯反派，不给怜悯——酒杯、大印都是兹鲁奇自己桌上的东西，她规规矩矩地「伺候」、规规矩矩地「办公」，暗里把两颗都毁了。和上一章「捧珠手滑」不同：这回是当着面、一本正经地做。

## 二、情绪设计

- **情绪锚点**：清早的不安 → 影像石败露的骤冷 → 女仆被交出去、门关上的愤怒 → 麻袋里压着火 → 开局被翻压、先泄一回的憋屈 → 夺下双头龙后带着火逼珠的狠 → 酒杯、大印的阴损痛快 → 项圈一按、瘫软受辱的骤落 → 警铃、毒气、陌生男人破门的荒唐。
- **微弧线**：低开（败露）→ 怒（女仆）→ 更低（被翻压先泄）→ 大抬（折叠、连逼两颗）→ 骤落（项圈、深喉）→ 被打断（警铃）→ 收在一个突兀的钩子上（兰斯破门）。
- **章内冲突阶梯**：①影像石败露 → ②女仆被交给男仆（她的火）→ ③被运进对方主场 → ④对方换了吸取教训的武器 → ⑤被锁腿对插、先泄 → ⑥翻盘逼出两颗 → ⑦对方掀桌用项圈 → ⑧外力打断（劫银行）→ ⑨毒气，她自己也躲不开 → ⑩陌生人破门。
- **信息差**：读者和她一起看见监视镜里那伙劫匪、听见兹鲁奇说漏口令门；她不知道来的是谁。项圈有机关，她和读者都是被按下那一刻才知道。兹鲁奇最后一眼停在「你们这群……」，下落留白。

**采用知识库方法论（匹配，不问作者）**
- 冲突升级：目标置换（兹鲁奇从「惩罚叛徒」到「性斗找场子」，再到「性斗找不回来，改用项圈」）→ 环境压力（钢板墙、刑架、主场、项圈）→ 连锁反应（败露 → 女仆出局 → 银行 → 劫案 → 毒气 → 兰斯）。
- 情绪拉扯：期待落差——兹鲁奇以为她服软了，一松劲就被翻；她赢了性斗，却被项圈按在地上。
- 钩子悬念：认知错位（兹鲁奇以为口令只有长官知道）；章末兰斯破门作悬念留白。
- 悲剧手法（轻用）：门一关、后面不写——留白比明写更狠。
- scene-craft：对话动作穿插（回合照底本，台词夹在动作里）；战斗结果导向（每回合落到谁占上风）；环境感官分层（麻袋里的颠簸与街声、办公室的钢板墙与血斑刑架、毒气沉在脚下的甜腥）。
