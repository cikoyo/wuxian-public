## 二、动机链与因果链（正文要能逐条对上）

### 1. 救熏

1. **为什么要救熏**：熏是这个世界里第一个来看她的人，教了她柔术，她拿柔术摔过兰斯、站稳了脚（上一章已立）。欠的人情，有能还的东西就还。不写温情独白、不写「好人有好报」式感慨。
2. **为什么去问系统**：医师没把握，兰斯要明天才去遗址碰运气，她手里唯一可能有办法的就是系统。问法一句，照第 18 章定稿格式「系统，……？」。

4. **为什么不买、用自己那瓶**：商店里的「复原圣水」跟她身上那瓶是一样东西（第二卷隐藏任务奖励，一直没用）。手里有现成的，不必再掏一百；价码记下了。一句心里话带过，不加引号，不盘算余额。圣水能修复中毒的身体，正文不解释（作者定）。
5. **为什么交给医师**：熏归医师管（上一章她被以「静养」为由赶出房间）。照原著 L1850–L1858：医师看药、看她，蘸一点尝了，决定用，说是他点头用的药，出了事算他的。原著「假装捉虫制药、背《本草纲目》」删（前世穿越梗）；医师问药哪来，她不答。

## 三、情绪设计

- **情绪锚点**：夜里土路旁的憋闷 → 商店弹出来 → 摸出自己那瓶的干脆 → 熏摔兰斯的轻快 → 熏从背后一抱、咬一口的措手不及 → 几个月进度不动的焦躁 → 夜路撞上猎物的兴奋 → 开局被撞、被摔、被大胸压住的狼狈 → 掐臀脱身、专打对方胸的狠 → 一拳打倒、以为赢了 → 被反扑闷到发黑 → 角力分出高下 → 腿锁逼泄、勒珠 → 闷晕、逼认输、牵人回去。
- **微弧线**：低开（熏垂危）→ 小抬（商店、救回）→ 软（熏的暧昧）→ 平（几个月）→ 抬（猎物）→ 落（开局吃亏）→ 抬（打垮大胸）→ 大落（被闷）→ 大抬（角力、逼泄、勒珠）→ 收在牵人回去。
- **章内冲突阶梯**：①熏命悬一线 → ②系统开店（她不花钱）→ ③进度几个月不动 → ④对手胸大、开局压制 → ⑤避锋击虚、打垮大胸 → ⑥对手爆发反扑、闷脸缠脖 → ⑦角力见高下 → ⑧腿锁逼出一颗 → ⑨闷晕、认输、活捉。
- **信息差**：虎姬以为凭胸稳赢；她一拳打倒对方时以为赢定了（两次「以为赢了」，一人一次）。熏知道药是她拿来的、不知道来路。

**采用知识库方法论（匹配，不问作者）**
- 冲突升级：环境压力（夜、水田、泥地）→ 连锁反应（胸被打伤 → 不敢再乳斗 → 只能闷脸、拼力气）→ 反转（L66–L77 以为赢了又被反扑）。

- scene-craft：战斗结果导向（每回合落在谁倒地、谁占位）；对话动作穿插（台词全照底本，夹在动作里）；环境感官（泥水、夜风、天边发白）。
