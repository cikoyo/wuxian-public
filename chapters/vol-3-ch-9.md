## 二、情绪设计

- **情绪锚点**：被叫醒的懒 → 有衣服穿的一点痛快 → 出门时背后有人看着的无所谓 → 见到林间两个人不意外 → 听洋葱摊账时的嗤笑 → 被抱着摔进落叶的恼 → 缠斗僵住的不耐烦 → 被翻下去压住时心里有数 → 胸被揉的恼（不是害羞）→ 攥裆翻盘的痛快 → 被甩下来顺势站起 → 「迟早睡到你」不接茬 → 走。
- **微弧线**：平（出洋馆）→ 小起（林间被堵、摊账）→ 起（扭打：僵持 → 她被压 → 她翻盘 → 被甩开）→ 落地（兰斯坐地、笑）→ 平（回村）。三场洋馆性斗之后喘口气，也把兰斯的念想重新挂起来，给第 28 章一战蓄力。
- **章内冲突阶梯**：①牢门开了，真放 → ②林间有人堵着 → ③洋葱亮出劫狱账，兰斯是「恩人」 → ④恩人扑上来抱着她摔倒，缠成一团 → ⑤头撞后他先翻上来，压着她揉胸 → ⑥她攥裆翻盘，骑上去捂嘴掐乳头 → ⑦被甩下，他坐地 → ⑧「迟早」。
- **信息差**：洋葱说「你和熏到底是哪里来的奸细」——晓柒月和读者已经知道熏是卧底（第 22 章），洋葱不知道她知道，她也不露；兰斯扛下劫狱读者第一次知道。扭打里两人都只用了几分：兰斯没下狠手（只想抱人、摸人），她也没往死里打——两边都留着，第 28 章才是真的。

**采用知识库方法论（Claude 匹配，不问作者）**
- 冲突升级：目标置换——出洋馆以为是「脱身」，林间变成「回到兰斯手里」；连锁反应——抱摔 → 缠腿僵持 → 头撞 → 翻身骑压 → 攥裆翻盘 → 甩下坐地，每一下都是上一下的回手。
- 情绪拉扯：期待落差——兰斯以为恩情摆着能直接抱人，落了个坐在地上捂裆；节奏控速——摊账段慢，扭打段快，坐地笑后再慢下来。
- 钩子悬念：「迟早睡到你」挂到第 28 章；洋葱「找我报仇都可以」挂到第 29 章套麻袋；她掂出兰斯力气大过诺薇，第 28 章她得换打法。
- scene-craft：战斗结果导向（每回合落在看得见的结果上：谁也压不住谁、额头一片红、她被翻到底下、他捂裆、她被甩下、他坐地）；对话动作穿插（洋葱慢条斯理、摊手；兰斯嘎嘎笑）；环境感官分层（洋馆二楼窗口的蝎娘、林间小路、大树、落叶、泥土）。
