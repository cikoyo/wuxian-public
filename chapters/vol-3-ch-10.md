## 〇、Memo（一句话）

她和兰斯回了村，村里人对着这个「被洋葱关过的女人」指指点点，她懒得理，照旧跟着绿队出任务。过了些日子，兰斯只带着几个老队员匆匆出了村；两天后村里传开了，西境那座给魔法屏障供能的魔力炉被兰斯炸了，屏障一弱，各地的激进派趁乱暴乱。又过了不到三天，村里的警钟急响、浓烟四起，魔物进了村。她本来要往人堆里跑，迎面撞上一个拖着受伤同伴的女骑士，后头三只两米多高的魔物在追；那骑士头盔底下是张漂亮脸蛋，她骂了自己一句，翻墙迎上去，让骑士带人先走，自己用柔术借力，让三只蠢大个儿扑空、撞成一团，把它们拖住。骑士跑远了，她正要撤，一道闪电从侧面劈来，是一只法师型魔物，她抽搐着倒在地上。眼看那东西走近，她问系统死在这儿会怎样，系统答：进度不低于 80% 可以脱离，低于就抹杀；进度弹出来，50%。她不再动，任它扛走，想抬头看一眼又挨了一道电。林子里，金甲魔物将军摘下自己的头盔，魔物把她剥光，从脖子的窟窿塞进它透明的缸状躯干，她沉进一缸绿液里，什么都感觉不到了。不知过了多久，她在杂音里找回一点意识，发现自己成了这东西的辅助大脑，能读到它的念头：村子被屠了一半，医师死了，兰斯回援才没灭村；赛斯王带着首都上百万人往外逃，魔物一路尾随。大约一个月后，魔物大军围攻迁徙队伍，「兰斯Attack——！」一声，缸被劈碎，兰斯把她从破口里拖出来。她一张嘴喷了兰斯一身绿水，浑身的电灼、碎缸划开的口子这才疼起来；兰斯嘎嘎笑着说脏成这样得带她去洗洗，抱起她就跑，她在他怀里花了一百性币，买了一瓶复原圣水喝下去，伤口一道道合上。

## 二、情绪设计

- **情绪锚点**：回村被指点的无所谓（顺手撩一下）→ 听说魔力炉被炸的嗤笑 → 警钟响时的利索（先跑）→ 看见漂亮骑士的鬼使神差 → 拖魔物时的轻快 → 被电倒的恼 → 问出 80% 线、看见 50% 时的一沉，随即务实（别动，活着）→ 挨第二道电的老实 → 被剥光塞缸时不羞、只觉得这东西邪门 → 缸里的闷和无聊 → 读到医师死了的一沉（人情还不上了）→ 读到首都大逃难的冷眼判断 → 被拖出缸时的狼狈好笑（喷兰斯一身）→ 买药的干脆 → 被兰斯抱着跑，懒得挣。
- **微弧线**：平（回村、出任务）→ 小起（魔力炉、暴乱，风声紧）→ 急起（警钟、魔物、救人、拖住）→ 骤落（被电倒，问出 80% 线，进度不够）→ 沉底（缸里一个月，屠村、医师死、大逃难）→ 破（兰斯一剑破缸）→ 回升（喷水、买药、伤口合上）→ 收在兰斯抱着她跑（给第 28 章淋浴帐篷）。
- **章内冲突阶梯**：①村里人的眼光 → ②兰斯炸了魔力炉，国家乱了 → ③魔物进村 → ④骑士被追到眼前，她选择出手 → ⑤三只魔物被拖住 → ⑥法师魔物一道电，她倒地 → ⑦死了要被抹杀、进度只有一半 → ⑧被剥光塞进缸里、断了五感 → ⑨村子被屠、医师死、首都逃难，她什么也做不了 → ⑩缸碎、获救 → ⑪浑身是伤，掏钱。
- **信息差**：读者和她同时第一次知道 80% 线；她知道自己只有 50%，兰斯和众人不知道她刚在生死线上走了一个月；兰斯「救了三回」第三回落地，兰斯本人还没开口要账（留第 28 章）。

**采用知识库方法论（Claude 匹配，不问作者）**
- 冲突升级：环境压力（魔力炉被炸 → 暴乱 → 魔物进村，一层压一层，都是背景推过来的）；连锁反应（她救人 → 拖住魔物 → 惹来法师魔物 → 被抓 → 塞缸）；目标置换（从「救个漂亮骑士」一下变成「别死」）。
- 钩子悬念：倒计时 / 信息差——80% 线揭开时进度只有 50%，把「死」从无所谓变成要命，压到终战；熏下落不明挂到第 28 章。
- 情绪拉扯：期待落差（她以为拖住了就能撤，侧面一道电）；节奏控速（救人段快、缸里段慢且压缩，「大约一个月后」一句跳过，破缸段再快起来）。
- 悲剧手法：惯性残留——医师死这件事只落在「人情还不上了」一句，不铺悲情。
- scene-craft：战斗结果导向（每一下落在看得见的结果上：扑空、撞成一团、倒地抽搐、缸碎、喷一身绿水、伤口合上）；对话动作穿插（骑士喘着说话、握剑不走）；环境感官分层（警钟、浓烟、喊声、脚步；林子里的金甲、空头盔、绿液；破缸时的哐当、哗啦）。
