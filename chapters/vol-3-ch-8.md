## 二、动机链与因果链（正文要能逐条对上；正文只写到一半，不补解释）

### 1. 迪柯拉为什么要第三关、为什么要打到底
1. 第 23 章他被她宫口咬射、骑射，软成一团，嘴里一直是「我不服！再来！」（台账）。他是洋葱拿来磨女人的，号称从不射——这是他全部的脸面，被一个刚抓来的女奴弄没了。
2. 希露的话交代他这几天谁都没碰、憋着劲（【原创】，作者卷纲方向「聊天里透出迪柯拉的底」）。他认定第一关是「先泄者输」占了便宜，换成打到底他才能把她肏到阴珠掉光。正文只写他在牢门外开口要第三关、要打到底（台词取材自 notes/20，或写手照第 23 章已立的粗口腔调写一句），不替他讲动机。

### 2. 洋葱为什么允许生死局
- 第 23 章洋葱说过，想破解她身上「没有一丝恐惧」（台账）。打到底就是拿命赌，他想看她怕不怕；迪柯拉死了，对他也不过是少一件工具。**正文只写洋葱慢条斯理地点头、解链子、坐下看，不写他为什么。**
- 规矩改动：第 23 章立的是「先泄者输」。这一关当面改成打到一方耗尽（迪柯拉开口提、洋葱点头），所以她中途泄了一回也不算输。规矩不重讲，只在开口那一句里带到（规则卡二·12）。

### 3. 她为什么应
- 第三关过了就三关全过、洋葱放人（第 23 章原话「等全都过了，就放你走呢」）。第一关她已经赢过他。男人的阳精算进度她早知道（第 23 章系统问答小修删了，但她心里有数）。**正文一字不写这些**（作者第 23 章删了「射出来的可都是进度」）。她应得干脆，一个动作或一个字（「行。」第 23 章用过，换）。

### 4. 她为什么榨死不留手
- 生死局本来就是打到耗尽（notes/00 第二节）；迪柯拉是强奸狂魔、纯反派，人物卡「对纯反派不给怜悯」。他瘫在铁栏边还在骂「迟早肏死你」，肉棒在她脚底下又顶起来——他自己不认输，她就接着榨。正文不写她的心里账，只写动作；他求饶（如果有）她不理。

### 5. 她为什么赢得了一个力气大她一截的男人
- 希露刚给她治好伤，身上没伤、腿不麻（因在第一节）。这场前半程不比力气、比手上功夫：迪柯拉憋了几天，第一下射出来的又急又多，射一回虚一回；她泄了一回没掉珠，诺薇的身子撑得住（台账「泄了也不掉珠」，第 19 章后没再用过）。只写动作，不解释。

## 三、情绪设计

- **情绪锚点**：睡醒的懒 → 希露在墙角「咿」一声的好笑 → 伤一下子不疼了的松快 → 被说不雅、懒得改 → 听见兰斯的名字就烦 → 听希露说迪柯拉的事、心里有数 → 牢门外迪柯拉开口要打到底，「来」→ 互撸时的较劲 → 把他的头夹在腋下的痛快 → 被扣穴、先泄一回的险 → 被抹水扇屁股的恼 → 膝盖一下下顶上去的狠 → 挨一拳、挨一脚的狼狈 → 踩住他、踩射的利落 → 捏着下巴撸到射不出的冷 → 一脚脚踩烂地上的精的轻蔑 → 他瘫着还骂、又硬起来的「行，那就接着来」→ 骑上去不动、只往里吞的耐心 → 他射空、没了气，她下来，平平地看一眼进度 → 进度跳一大截的「哦」→ 项圈撤了、明天能走，懒懒地躺回小床。
- **微弧线**：平（睡醒、治伤）→ 小落（兰斯的名字）→ 抬（迪柯拉的底）→ 紧（打到底）→ 抬（锁颈）→ 落（被扣穴先泄）→ 抬（膝碾）→ 落（挨拳挨脚）→ 大抬（踩射、撸空、踩精）→ 小落（他又硬起来）→ 大抬（骑上去榨死）→ 平（看进度、撤项圈），收在她躺回小床或洋葱一句「明天就可以走了呢」。
- **章内冲突阶梯**：①项圈锁墙 → ②迪柯拉要打到底 → ③互撸僵持 → ④她先泄一回（规矩已改，不算输）→ ⑤拳脚互换挨打 → ⑥踩射、撸空 → ⑦他死不认输、又硬起来 → ⑧骑上去榨到射空而死 → ⑨三关全过、撤项圈。
- **信息差**：迪柯拉以为憋了几天就能把她压垮（其实憋得越狠，头一下射得越急越虚）；读者从希露嘴里先知道他憋着，比迪柯拉早半步看到他那股劲是空的。洋葱以为生死局能逼出她的怕（她从头到尾没露一点），读者看见洋葱坐在铁栏外一直盯着她的脸。

**采用知识库方法论（匹配，不问作者）**
- 冲突升级：环境压力（项圈、四五步的牢房、力气差）→ 目标置换（第三关从「过关」换成「打到底」，先泄者输作废）→ 连锁反应（她先泄 → 被羞辱 → 膝碾 → 挨打 → 踩射 → 撸空 → 他又硬 → 骑上去榨死）。
