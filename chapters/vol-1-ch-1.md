## 大纲（outline）

- **概要**：林叁玖发帖问怎么回去被群嘲；接到奶奶的死讯要回村，抽到 D 级「初级魅魔血脉」和 D 级「魔镜真言」，冒雨出楼时眼前一黑，被载入【剧情世界：汉宫争艳】。
- **出场角色**：林叁玖；网友（只以回帖出现）；村长（只有电话里的声音）；同事（提醒带伞的那位，不起名）；原主记忆里的同事、新闻里的人（只在记忆画面里）。
- **场景地点**：大本营·写字楼工位 → 写字楼外雨街。
- **时间**：夜里，下班前；雷阵雨。
- **视角（pov）**：林叁玖（单主角有限视角）。非性斗章，不进同事、村长、网友的内心。
- **字数目标**：2500–3000 字（软指标，不为凑字数加内容）。

### 关键点（情节区：只写动作、台词、看得见的反应）

1. **[造悬念·开篇]【1.txt】发帖被嘲，倒回半小时前**
   工位电脑屏上是她刚发的帖：「穿越了，怎么回去？」→ 回帖一条接一条往下刷，都是嘲（改写 1.txt L4–6 的三层意思：一本正经胡说八道 / 穿越剧看多了、想穿到古代被皇帝王爷宠上天 / 闲了就去看看银行卡余额）→ 林叁玖的手搭在键盘上，没再打字。
   倒回半小时前：监狱大门在她身后关上 → 脚刚迈出去，整个人往下一坠 → 再睁眼，是灯火通明的写字楼、挤满人的格子间、四面八方的键盘声，她坐在一个乱糟糟的工位上。原主的记忆一段段涌进来 → 她认出这是她看过的一本小说（**不说书名**），她在书里是个没名字、注定横死的炮灰。
   她只看了这本书的开头一小截，后面的剧情她不知道。
   按书里的剧情，二十分钟后，一股神秘的力量将席卷全球，所有人都会被卷进去（**不说「规则怪谈」，不用「副本」**）。
   感官侧重：屏幕光、键盘声。

2. **[推进剧情·世界常识]【原创提案】原主记忆里的日常**
   原主记忆里的画面：两个同事（不具名）闹了矛盾，约好下班去「比一场」，一句带过；新闻里某某性斗落败身亡（只写「落败身亡」，不出现「阴珠」）。→ 林叁玖对这个世界吐槽一句（冷、短，心里话，用单引号）。
   只剩十分钟。格子间里敲键盘、点鼠标的声音越来越响。

3. **[推进剧情·对话]【1.txt】村长来电，同事提醒带伞**
   手机响，陌生号码 → 她接起来 → 粗哑的男声：「小玖快回村里，你奶奶咽气了！」→ 那人自称村长，叫她赶紧回去办丧事（不说村名）→「好，我马上回去！」→ 她关掉那条被围攻的帖子，抓起手机往外冲——原主由奶奶一手养大，那股悲痛是原主的，压过了她自己（**作者 2026-10-01 定：这里写出原因**）。
   身旁的同事一把拽住她：「你去哪儿啊，还没下班呢！」→ 林叁玖被拽住才回过神，一顿 →「我……有点事要先走，你帮我请个假。」→ 同事没往下问：「行，那你出去记着拿伞，今晚有雷阵雨，注意安全。愿神勇的波塞冬大人庇佑你。」→ 林叁玖点头，拿起工位旁那把透明雨伞，头也不回地走。

4. **[推进剧情]【1.txt】撑伞站进雨里，抽天赋**
   还有两分钟。→ 她撑开透明伞走进雨里：雷声轰响、瓢泼大雨，她站在雨里抬头看了一眼办公楼。
   脑子里突然响起一声像程序启动的「滴答」→ 系统提示：
   【叮！首次进入的试炼者，可以获得两次抽取天赋的机会：性斗天赋一次，非性斗天赋一次。】
   【系统正在为您抽取性斗天赋……】
   → 她想起原书：女主抽到 S 级【雅典娜的智慧】和 S 级【阿佛洛狄忒的祝福】，男主抽到 SSS 级【捣蛋鬼】和 SSS 级【无限射精】（只写名字和等级）。→ 她站在雨里等结果，心里多少有点期待（**作者定：可以写「期待」**）。
   【恭喜您随机抽到D级性斗天赋——初级魅魔血脉。】
   【初级魅魔血脉天赋介绍】
   【1.你的体液带有轻微的催情效果。】
   → 期待落了一半：烂大街的天赋。她记得书里说过，九成的人最多只能把它升到 C 级「普通魅魔血脉」。
   【系统正在为您抽取非性斗天赋……】
   → 天赋文本（**照录 1.txt L55–58，一字不改**）：
   【恭喜您随机抽到D级天赋——魔镜真言。】
   【魔镜真言天赋介绍】
   【1.当别人向你提问时，你必须说真话。】
   【2.你将永远知道世界上最美丽的女人是谁。】

5. **[推进剧情·吐槽]【1.txt】让欺诈师只能说真话**
   「……就这？」林叁玖噎住。→ 吐槽（心里话，单引号，短）：系统抽天赋都不做背景调查的吗？她进去之前可是个欺诈师——让欺诈师只能说真话。
   保留 1.txt L63–67 的比喻串（上战场不让带枪、进考场忘带笔、刮刮乐没中还倒扣十块）和「有人一出生就在罗马，她的起点是贫民窟」，改写措辞；**「一切只能靠自己」删去**。

6. **[造悬念·章末]【原创提案】眼前一黑**
   雨还在下，伞在她手里 → 眼前一黑 → 提示音：
   【剧情世界：汉宫争艳，载入中。】
