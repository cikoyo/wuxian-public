## 二、情绪设计

- **情绪锚点**：回到自己身体的踏实 → SSS 的痛快 → 解开阎王帖的满意 → 真言升出来的失望（嫌没用）→ 大殿与神像的兴致 → 「让神认你无罪」的莫名其妙 → 守则念下来的荒唐 → 想通陷阱时的一冷 → 看陆苏变脸的幸灾乐祸 → 被侍卫当众叫狐狸精的嫌 → 被大祭司划成「骚的那种」、发去拖地的无所谓 → 换上白裙、胸口绷紧的别扭 → 拖地时的平 → 撕破的裙片带来的警觉 → 小鸮盯人那一下的寒。
- **微弧线**：高开（结算、加点，全是她占便宜）→ 平（大殿、任务）→ 往下压（守则、陷阱、侍卫、被嫌骚）→ 落在一个静里藏险的点上（裙片、小鸮）。不写悲情，不写害怕，她始终是懒的、看戏的、挑剔的。
- **章内冲突阶梯**：①系统要她证明自己无罪（她什么都没干）→ ②守则：失贞一经发现即有罪、三遍禁止勾引 → ③派活的是侍卫，男人开口不能拒 → ④侍卫当众围看、品评女人身体 → ⑤大祭司亲口把她划进「骚」的那一类 → ⑥石柱角落一截撕破的裙子：规矩底下已经有人出了事 → ⑦小鸮盯着她。停。
- **信息差**：读者和晓柒月同步。读者记得大祭司是第二卷的考官，不知道她就是雅典娜（第 6 章揭）；「不知何时站到神殿中央」只作一处异常，不点破。「蛇女是什么」留一个疑问（第 5 章丝西娜）。撕破的裙片只给结果，谁撕的、撕谁的，本章不答（第 2 章侍卫甲一场自然接上）。

**采用知识库方法论（Claude 匹配，不问作者）**
- 开篇钩子：极度反差——SSS、六百多枚性币、刚升级的天赋，一转眼被发去拖地；矛盾前置——系统要她证明「无罪」，她连罪名都没有。
- 冲突升级：环境压力（守则、侍卫、小鸮层层压上来）；连锁反应（位分规矩 ＋「一经发现」→ 陷阱自己成形，由她一句复盘点出）。
- 钩子悬念：认知错位（无罪任务）；信息差（大祭司凭空出现在神殿中央、「蛇女」）；悬念留白（撕破的裙片）。
- 情绪拉扯：期待落差（升级 → 只会逼她说真话的真言；人人抢着要 → 被嫌太骚扔去拖地）；节奏控速（结算一口气弹完，守则慢慢念，派活快，拖地慢下来）。
- scene-craft：对话动作穿插（侍卫派活，一句品评跟一个女人的反应）；环境感官分层（大殿的金与白、烛火贡品、神像的高、白裙像医院的消毒水味、侍卫鞋底的沙和泥脚印、墙上多出来的圆影子）。
