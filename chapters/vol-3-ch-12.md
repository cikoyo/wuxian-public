## 二、情绪设计

- **情绪锚点**：帐篷散场的懒 → 听说讲和、劫狱没人追究的嗤笑 → 熏露面「果然」的得意（小暧昧一闪）→ 一线杀魔物的痛快 → 套麻袋揍洋葱的解气 → 乌鲁泽谈团结的识趣 → 兰斯当上领队、吹牛睡了王女的白眼 → 要塞里进度往上跳的愉快 → 撞见阿鲁贝特时的莫名其妙 → 传送时的晕 → 醒来「兰斯命大」的随口 → 阿鲁贝特揭莉兹娜伤疤时的不痛快 → 听到「诺薇失去魔法是我干的」，诺薇的情绪往上涌、她自己嘴上一句「就这？」→ 被一脚踢飞 → 醒来被乌鲁泽护在身后，她不领情、上前并肩 → 春药发作，身子软了，眼睛却亮了。
- **微弧线**：平而轻快（讲和、一线、揍洋葱，全是她占便宜）→ 小起（要塞、使徒露面）→ 急转（传送、自曝、一招打倒，全书她第一次被人一下放倒）→ 低（醒来同困、中毒）→ 收在一个往上翘的点：她看中了下一个猎物。**不写悲情、不写恐惧**，作者口径「没有额外压力」。
- **章内冲突阶梯**：①旧账（洋葱）→ ②任务（要塞点火）→ ③间谍现身 → ④陷阱打散队伍 → ⑤真凶自曝（诺薇的人生是她毁的）→ ⑥武力碾压，一招倒地 → ⑦下毒，解药是投降 → 停。
- **信息差**：读者和晓柒月同时知道阿鲁贝特是一切的祸首；阿鲁贝特以为她们只有「屈服或熬着」两条路，不知道晓柒月把她当猎物；乌鲁泽、莉兹娜不知道晓柒月根本不怕死（80% 线只有她和读者知道）。

**采用知识库方法论（Claude 匹配，不问作者）**
- 冲突升级：反转误导（「友军」→ 间谍 → 一切的祸首）；连锁反应（陷阱 → 分散 → 同困 → 下毒）；目标置换（点火任务 → 自保 → 面对使徒）。
- 钩子悬念：信息差（她不怕、对方不知道）；倒计时（L5187「发作时感觉会一点点增加」，交给第 30 章）；章末停在「解药是精液」这个两难上，读者知道她会怎么选。
- 情绪拉扯：先糖后刀（前半全是顺风：讲和、杀魔物涨进度、揍洋葱、要塞一路无敌 → 后半一招被打飞）；期待落差（她以为柔术接得住，飞了）。
- 悲剧手法：惯性残留——诺薇失去魔法这件事，落在诺薇身体的一下情绪上涌，不落在晓柒月嘴上。
- scene-craft：战斗结果导向（忍者蜷成虾米、她倒飞出去、醒来胳膊火辣辣）；对话动作穿插（自曝段每句台词后跟一个人的反应）；环境感官分层（传送时「滋滋」声、眼前扭曲、晕；同困屋里两人的喘声、身上的热）。
