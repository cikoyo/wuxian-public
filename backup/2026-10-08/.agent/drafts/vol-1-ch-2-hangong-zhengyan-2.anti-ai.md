## anti-ai 问题清单（只列不改，交作者逐条 OK/NG）

### 一、作者点名的 AI 腔及同类句（重点）

1. **原句**：紧跟着，一段段不属于她的记忆往脑子里挤，这具身体的主人是宫里的王美人，最先挤进来的，就是胸口这片红的来历。
   → **问题类型**：谜语式强调，句中硬加逗号（「最先挤进来的，就是……的来历」）；「不属于她的记忆」是穿书文套话（存疑）
   → **建议改法**：紧跟着，一段段记忆往她脑子里挤，这具身体的主人是宫里的王美人，最先挤进来的是胸口这片红怎么来的。
   → **理由**：nonfight 硬约束 13「回忆用完整陈述句直说，不为顿挫在句中硬加逗号」；「的，就是」这种断句跟被点名的「何贵人笑着邀王美人，去永巷观水」是同一种停顿。

2. **原句**：那天何贵人邀王美人去永巷观水，王美人应了下来，跟着她去了。（下一段接「两人到了永巷」）
   → **问题类型**：动作三连拍（应了 → 跟着去了 → 到了，同一件事走三步）
   → **建议改法**：那天何贵人邀王美人去永巷观水，王美人应了。（或整句只留「何贵人邀王美人去永巷观水」，直接接「两人到了永巷」）
   → **理由**：「跟着她去了」和下一句「两人到了永巷」说的是同一件事，原地踏步。

3. **原句**：记忆没停，接着往下翻，一段比一段快。
   → **问题类型**：描写快慢（与被点名的「一行一行，不紧不慢」同类）；「没停」「接着往下翻」同一意思说两遍
   → **建议改法**：删整句，出记忆后直接接「宋皇后被废……」；或只留「记忆接着往下翻。」
   → **理由**：「一段比一段快」是提示词里给写手的节奏说明，被原样写进了正文；原作不写东西出现得多快。

4. **原句**：宋皇后被废了。／王甫被诛。／何贵人被立为皇后，从此成了何皇后。
   → **问题类型**：碎句（四字一段，一个意思切成几截）；「被立为皇后」「从此成了何皇后」同义重复（存疑：提示词要求「一件事一句」）
   → **建议改法**：合成一句完整陈述句「宋皇后被废，王甫被诛，何贵人被立为皇后。」下一句「何皇后在长秋宫设宴……」自然完成称呼切换。
   → **理由**：nonfight 硬约束 2、13；原作回忆用完整长句说「谁、做了什么、结果如何」，不写四字一行的节拍。

5. **原句**：林叁玖心下一沉，胸口这片红还没消，说明她醒在永巷那场乳斗刚结束的时候，宋皇后被废、王甫被诛、长秋宫那场宴，全都还没发生，而记忆最后那一下倒地，就是这具身体的死期。
   → **问题类型**：相邻段重复（把刚列过的三件事再列一遍）；句中硬逗号（「……那场宴，全都」「倒地，就是」）
   → **建议改法**：林叁玖心下一沉，胸口这片红还没消，说明她醒在永巷那场乳斗刚结束的时候，后面那些事全都还没发生，而记忆最后那一下倒地就是这具身体的死期。
   → **理由**：nonfight 硬约束 4「一个事实只说一遍」；推理本身保留。

6. **原句**：……可这具身体已经在那个女人手里输过一回，说明她要赢的，恰恰是这具身体最赢不了的人。
   → **问题类型**：自造对称俏皮句（「要赢的 / 最赢不了的」）+ 句中硬逗号；「输过一回」推不出「最赢不了」，「说明」接不上
   → **建议改法**：句子停在「……可这具身体已经在那个女人手里输过一回。」；或平说「……可这具身体已经在那个女人手里输过一回，她要去赢的，是一个这具身体已经输给过的人。」（后者仍略绕，推荐前者）
   → **理由**：与被点名的「胸是大了一圈，疼也跟着大了一圈」同类——用字面对称造句，不是推理。案例二要求推理写在明面上，对称句把推理换成了俏皮。

7. **原句**：怨魂哭着往前凑，黑血和眼泪混在一起，一滴一滴落在席子上，她边哭边说，一句一顿。
   → **问题类型**：原地踏步（「哭着」「边哭边说」）；「一句一顿」描写说话节拍（与「一行一行，不紧不慢」同类）
   → **建议改法**：怨魂往前凑，黑血和眼泪混在一起，一滴一滴落在席子上，她边哭边说。（红线要求的「边哭边说」保留，删句首「哭着」与句末「一句一顿」）
   → **理由**：同一动作说两遍；节拍描写是给写手的说明。

8. **原句**：（L121）……三句话化成血字，留在了林叁玖的脑子里……／（L123）血字还留在脑子里，林叁玖撑起身子，低头看这具身体。
   → **问题类型**：相邻段重复（「留在脑子里」连说两次）
   → **建议改法**：L123 删「血字还留在脑子里，」，改为「林叁玖撑起身子，低头看这具身体。」
   → **理由**：writing-memory 第 6 条「同一句描写不在相邻段落重复」。（存疑：章纲衔接写了「血字留在脑子里，她撑起身子」，写手是照衔接写的）

9. **原句**：……她只过了一遍就全记下了，好在干她们那行的，记性向来是吃饭的本事。
   → **问题类型**：藏关键词（「她们那行」不点明是骗子）；一句塞了散雾、化字、记住、态度四件事（存疑，写手问题 7 已提）
   → **建议改法**：在「全记下了」处断句，另起一句直说：「好在她当骗子那些年，记性向来是吃饭的本事。」；或按写手的备选只留「她只过了一遍就全记下了。」
   → **理由**：原作同处写法是直说「暗中庆幸自己记性好」，不打哑谜。

10. **原句**：这具身体腰细，臀圆，乳房比原身还要大一圈，胸口那片红就印在两团乳肉中间。
