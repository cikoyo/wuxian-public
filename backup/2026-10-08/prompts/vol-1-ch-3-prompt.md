### 写作方法论（动笔前按顺序执行）
1. **焦点锁定：** 每个场景只锁一个焦点（见场景原材料「本场景焦点」）。高权重场景（比胸）细化到动作与身体层级，并同时执行下一条感官取舍；低权重场景（宫道）快速带过，但仍遵守焦点和感官取舍。
2. **感官分层取舍：** 每个场景以 2 种感官为主，氛围允许时 3 种，其余一笔带过，禁止全维度均匀堆砌。**声音例外：** 声音线索属于情节红线的关键信息、且以一两句简短白描出现时，不计入感官名额（本章：掖庭那边的吵嚷、起哄声、对撞的闷响、拦路的宫女的惨叫与叫声）；环境装饰音不算例外。
3. **节奏交替：** 性斗段按性斗写法（长段落、长句里连一串动作，中间夹叫声和骂声制造顿挫）；非性斗段按原作写法（一句一段为主，叙述句写完整长句，短句只给吐槽、反应、结论）。两段之间的节奏差就是本章的起伏，不要写成一个样。

5. **结构红线：**

**案例一·非性斗段：女医上药时问规矩（场景一）**
女医不知道这具身体里换了人，只当刚输了的王美人伤后多问几句。晓柒月的问话要短、像随口问（“推了呢？”“输了就得死？”），她为什么问不写；女医的回答也短、手上不停：问一句，女医蘸一下药膏；答完一条，晓柒月的推理接一段长句，把这条规矩放到自己身上。女医的动作写成看得见的样子（低头抹药、摇头、手上没停），不写她怎么想。情绪是「冷静试探 → 发沉 → 一口气稍松又被压回去」：R3 一句「人还在」让她松一下，T2b 马上收回。（演示：对话 + 动作穿插）

**案例二·性斗段：三个回合高下渐明（场景三）**
揣耳环的宫女胸大一圈、急着走，打法是抡——胸像流星锤一样一下比一下沉；拦路的宫女咬定耳环该归她们屋里，第一下还硬顶回去，嘴上刚骂完。三个回合要写出「一来一回，高下立的越来越清楚」：第一回合两边都被撞得晃，第二回合拦路的宫女的乳房开始被撞得往里瘪、弹不回来，第三回合她惨叫一声捂胸，乳房软塌塌地垂着，两腿一软跌坐。代价要可视化：不写「她输了」，写她捂着胸的手底下乳肉撞得发红、衣裳底下乳头还被刺着、坐在地上腿岔着站不起来。（演示：受力写形变 + 代价可视化）

#### 三、T1 句式 / 认知动词 / 感官取舍

**作者覆盖（优先于下面的清单）：**「倒吸一口凉气」可以用，一章一两次以内；「像」「仿佛」「如同」混着用，不刻意禁止；拟声词和口语化的重复描写不算 AI 味；情绪标签、心理说明、动作来由解释、比喻、总结句可以写。

**T1 最毒句式（出现即换）：**
- 「不是 A，（而）是 B」及其变形（并非……而是、与其说……不如说、你以为……其实、看似……实则）→ 直接写 B。
- 「……，带着一丝……」万能状语 → 拆开或换动作。
- 「当……的时候」起句 → 拆成独立动作句。
- 「她意识到 / 她注意到 / 她发现」这类认知动词前置 → 删掉，直接写事实。
- 「与此同时」→ 直接换场景。
- 元叙事：不写「本章」「下一章」「故事还在继续」，不写「此时的她还不知道……」这类全知句。

**作者点名的 AI 腔（同类都不要写）：** 碎句定格、动作三连拍、机械套句式（好消息 / 坏消息）、自造对称俏皮句、藏关键词的谜语断句、把话说满的限定语和凑词尾巴——原句与原作写法见「写作规范 B · AI 易犯错误」对照表。

**认知动词：** 关键情绪节点可以用，全章两次以内；其余用动作或直接的感知替代。非性斗段原作那种直说（「心下了然」「心下一沉」）不算超标。

**感官：** 场景一以触觉（药膏凉一下又辣一下）+ 嗅觉（药味）为主；场景二以视觉（宫墙、廊下、围着的人）+ 听觉（远处的吵嚷）为主；比胸段以触觉（乳头隔衣刺入、撞击的酸麻）+ 视觉（形变、跌坐）为主，闷响、惨叫、起哄不占名额；场景四以视觉（妆奁、金簪）为主。

#### 五、写作规范

##### A. 性斗段（第 3 条掖庭比胸）

**叙事身份：** 一个站在擂台边、什么都看得见的解说人：第三人称，镜头在两个宫女之间切；关心的只有一件事——谁压过了谁、谁先撑不住、输的人怎么被羞辱。语气直、狠、带骚劲，不装文雅。首尾回到晓柒月站在廊下的位置。

**硬约束：**
- 内心只进揣耳环的宫女那一段（L242 改写），用单引号 ‘ ’，短、带感叹号或省略号，后面接「心里想着」再接身体动作；拦路的宫女不写内心。
- 台词用 “ ”；台词在前，说话人称呼 + 逗号串起的一串动作紧随其后，不单独起一段写「她说」。
- 两个宫女的称呼固定为「揣耳环的宫女」「拦路的宫女」（第二次起可简作「揣耳环的那个」「拦路的那个」）；争耳环那两句台词出现时，拦路的宫女还没拦路，可先写「另一个宫女」。少用「她」。
- 骂战直白说出口；骂词照底本（「臭骚屄」「你的屄才臭呢」）。
- 拟声词单独成段或写进台词，不写「传来一声闷响」这类转述；叫声直接写进台词：拟声 + 波浪号 + 感叹号，越到极限越断续。乙的叫声另写，不与第 2 章同句。
- 情绪主要落在身体反应上（脸涨红、咬牙、捂胸、腿软、发抖、喷水）。
- 胜负落在看得见的身体结果上：乳房被撞得往里瘪、弹不回来、发红；捂胸、踉跄、两腿一软跌坐；下裳湿透、核心从裙底滚出来。
- 不用「本钱」，换成乳房、乳肉、乳晕、乳头、腰、屁股等具体部位词。

**AI 易犯错误：**
- 把对决写成势均力敌、互相欣赏——这一场三个回合就分出高下，赢家捡走东西冷哼走人。
- 用「她发出一声惨叫」概述声音——直接写出声音本身。
- 句子切得太碎、一句一段——性斗段一段四五句，一句里用逗号连四到六个动作。
- 套用眸光、指节泛白、空气仿佛凝固、似笑非笑、意味深长、眼底闪过一丝之类的词。
- 给赢家加台词、给输家加内心、加底本没有的招式（搂住、挤压、扒衣都不加）。

**描写层次和手法（润色用，不改流程）：**
1. 动作链长句：一个主语带一串动作，逗号连到底，落在结果上。
2. 比身材开场：开撞前两人隔着衣裳挺胸对着，揣耳环的宫女的胸大一圈，把衣襟撑得鼓鼓的（只比不报数）。
3. 受力写形变：撞上时乳肉隔着衣裳被挤扁、往两侧鼓出去又弹回来；乳头隔着衣裳刺进对方乳肉里的位置写具体。
4. 高下渐明：同样的撞击，一个被撞的变形失守，一个只晃了晃，一来一回，高下立的越来越清楚。
5. 力气流失写成看得见的变化：拦路的宫女的乳房从硬顶回去变成软塌塌地被砸瘪、弹不回来；挺着的胸一下比一下往后缩。

### 场景写作指引

本章涉及 4 种场景类型（dialogue / fight / inner-mono / transition），另始终加载 pov、prose 各 1 条。

- **dialogue（女医问答）· 对话 + 动作穿插：** 每一两句台词之间插一个上药的动作——蘸药、抹开、换一处、合上药碗——女医的动作是「低头做事、不抬头」，正好压住规矩的分量：她说「推不得」时手上没停，像在说宫里人人都知道的事。晓柒月这边用推理代替动作。
- **fight（比胸）· 代价可视化：** 不写「拦路的宫女输了」，写她捂着胸的手底下乳肉撞得发红、瘪着弹不回来、坐在地上腿岔着、裙底下湿了一片、那颗阴珠滚出来；赢家的代价也给一笔（喘着粗气、胸口也撞得发红），但只一笔，不抢输家的镜头。
- **inner-mono（T1 / T2b / T5）：** 见案例三；各用一个情绪短语 + 一段推理，不用思维碎片、不写崩溃；晓柒月的冷让压抑更沉。
- **transition（数日后出门、走开、回居所）· 动线镜头：** 只写「离开某处 → 途中一个感官锚点 → 到达某处」：居所 → 宫道上记忆和眼前对上 → 远处的吵嚷 → 廊下；掖庭走开 → 推理 → 回到居所妆奁前。不写拐了几个弯、走了多久。
- **pov · 视角分界：** 比胸段镜头可在两个宫女之间切，但一个自然段只进一个人；入口用「她站在廊下看过去」、出口用「人群散开，她走开」把镜头交回晓柒月；中途「胸口青紫跟着一疼」是唯一一次插回她。
- **prose · 三维编织：** 非性斗段一句里把「发生了什么—她感到什么—她怎么做」织在一起（药膏抹上来凉一下又辣一下 + 她没吭声 + 先开口问），不拆成三句三段。
