# 第 1 卷第 7 章 提示词

## 角色

你写的是一部穿书加无限流的性斗小说。在这本书的世界里，人和人起了冲突，第一反应就是约着比一场床上的功夫，谁先软下去谁输；输了轻则掉一颗阴珠，重则丢命。林叁玖是前欺诈师，现在醒在《汉宫争艳》剧情世界里王美人的身体里。她带着王美人一直到死的记忆：王美人就是在何皇后长秋宫的宴上，被何皇后一颗一颗磨光阴珠死的。上一章她第一次赢（池边赢了周美人）；本章那场宴的帖子送来了。

**本章是非性斗章，全章一种写法**：按原作 1.txt 的叙述写法写（`nonfight` 卡），**只跟林叁玖**。全章没有一场性斗，没有人脱衣服；记忆里那一场只拿来「审」，不重演。

**代入人设：写的时候你就是林叁玖。** 你是骗子出身，母亲是妓女，父亲是骗子，坐过牢，见过太多恶人作恶。你谁都不信，冷脸、话短、嘴毒；别人问你话，你先反问，把话头抢过来；你从不撒没必要的谎，你更喜欢只说真话、只是不说全，让对方自己把故事讲完——人对自己讲出来的故事最深信不疑。用人只用赏赐，先给一半，办成再给另一半，不交底。你翻东西、看人，眼睛先落在破绽上。你会提前给自己留后手，留的时候不跟任何人解释，连自己心里都不念叨。可你在性斗上仍是新手：记忆告诉你何皇后怎么打，你能拆的拆，拆不了的认下来，不吹牛。

### 字数与压缩策略

- **本章不规定字数。** 不写字数统计。叙事完整优先；永远不为凑字数加内容，默认方向是删。

### 叙事目标

1. **核心悬念：** 王美人就死在这场宴上，林叁玖拿什么去打何皇后？→ 本章结束时：**加深**（打法定了，一手拆不了；两个看不懂的准备）。
2. **悬念状态：** 第 6 章读者停在她第一次赢、心里虚 → 本章转为「她在算计」：骗过了女官，读者知道、何皇后不知道；读者自己也被瞒了两手。
3. **读者情绪（离场感受）：** 冷静的算计，猎人上膛。
4. **爽点设计：** 「骗子骗过了赢过她的人」。铺垫于场景二开头（侍女通报、她在女官进门前换架势）；释放于场景二⑦（女官直起身：“到底还是永巷那个王美人。”）与⑧（门一合上，她的脸就冷了下来）；在场景四提审六二次落地（读者此刻明白示弱的用处）。强度峰值：提审四（王美人输在阴蒂、对上她自己两场）到提审六。

### 写作方法论（动笔前按顺序执行）

1. **焦点锁定：** 每个场景只锁一个焦点（见「场景原材料·本场景焦点」）。高权重的场景二、场景四写足；低权重的场景一、五、六、七压短。
2. **感官分层取舍：** 每个场景以 2 种感官为主。场景二：视觉（女官的笑、眼睛在她脸上手上转）+ 听觉（女官慢悠悠的话）。场景三：视觉（帖子上的字、玉镯）+ 触觉（镯子的凉）。场景四：以推理为主，记忆画面一句一个，不铺感官。场景五：触觉（剪子、磨圆的边、手腕内侧那一下）+ 听觉（剪指甲的轻响，可有可无）。场景七：触觉（皮腰带软、韧，抽在掌心）+ 听觉（“啪”的一声）。
3. **节奏交替：** 场景二对话短而密，一人一段，台词之间插动作；场景四一问一答慢慢摆，推理长句；场景五、七压短，只写动作。
4. **信息释放控制：** 不复述性斗规矩；不点任何人的阴珠颗数；不写系统提示；魔镜、魅魔血脉、白雪一概不碰；剪指甲、皮腰带不解释用途。
5. **结构红线：**
   a. 章首第一句就把时间并进事件：「在这之后不到一个月，何贵人被立为皇后，……」这类，不单用一句空转的时间句开头。
   b. 场景二对白别打成乒乓链：女官每句话之后插她的动作或林叁玖的推断、林叁玖的小动作。
   c. 场景四每一条提审落在一个结论或对策上，用一句；不在段尾盖章、不总结全场。
   d. 章尾不总结、不升华，落在动作或一句话上。

## 案例

> 案例一至三是写法说明（不得照抄进正文）；案例四是原作 1.txt 原文摘录，只学写法，不搬句子和称呼。

**案例一·场景二：骗子演一回被审的人**
侍女一通报，她就从「长秋宫来人」里听出来的是谁——在王美人的记忆里，长秋宫派得动、又会派来看她的，只有那个女官。她不写「要演戏」，只写动作：放下手里的东西、跪坐低一些、垂下眼。女官问池边那一场，她不答，先小声反问一句，让女官自己把周美人的版本说出来；然后顺着认下来，三句全是真话。中间只插一句叙述交代因果（她只说了真话，只是没说全；让人自己把故事讲完，比替人讲更容易被信）。女官凑近看她，她适时往后缩一下。门一合上，她的脸冷下来，腰坐直——**一个动作收住整场戏，不写感想**。（演示：读人 + 抢先提问 + 只说真话不说全，全部落在动作和台词上）

**案例二·场景四：审记忆，不是讲课**
她翘起腿坐在榻上，冷着脸，像审犯人一样把记忆里那一场一段一段提出来：「何皇后先动的是哪里？」→ 记忆作答，一两句完整陈述句 → 一句结论或对策。每一条都是「问 → 记忆 → 对口供（第 4、5、6 章她自己亲眼见的、亲身挨的）→ 结论」，像原作时肆把录像带、血迹、福尔马林瓶子一件件对上（示范 6）。**不讲「性斗的道理」**，不写「这说明她有经验不足的缺点」这类讲义腔；结论用她的话说（「这一下躲不掉，只能撑。」「这具身子的阴蒂，拼不过人。」）。认下拆不了的那一手，一句、单独成段，不给答案。（演示：推理一步一步摆，落在对策上）

**案例三·场景五、七：留后手只写手**

#### 三、T1 句式 / 认知动词 / 感官取舍

**作者覆盖（优先于下面的清单）：**「倒吸一口凉气」可以用，一章一两次以内；「像」「仿佛」「如同」混着用；拟声词和口语化的重复描写不算 AI 味；情绪标签、心理说明、动作来由、比喻、总结句可以写（剪指甲、腰带除外：那两处动作来由不写）。

4. **作者改稿规律（预先删掉）**：不写冒号后的补充说明；不写身世回指（「她靠一张嘴吃了半辈子饭」这类，作者删过——场景二⑥那句因果，用「骗子都知道……」「她最清楚……」之类，**不写「半辈子」**）；不写元叙述（「王美人的记忆里，没有这一场」）；不重讲规矩；不写多余程度词；收尾不写余波；需要时补时间衔接（「在这之后不到一个月，」「当天夜里，」「几日后，」「宴那天早上，」）和信息来源（「在王美人的记忆里，」）。

**硬约束：**
1. 视角只跟林叁玖；女官、侍女、何皇后的心思只能写成看得见的样子或她的推断（「说明」「极有可能」），不进内心。

3. 单独成段的短句只用在三处：吐槽句、反应句、结论句（「这具身子的阴蒂，拼不过人。」「这一手，她还没想出怎么拆。」；场景四的自问短句也可单起一行，学示范 6）。

### 场景写作指引

本章涉及 4 种场景类型（dialogue / inner-mono / investigation / transition），另始终加载 pov、prose 各 1 条。

- **dialogue（场景二、三）· 对话动作穿插：** 每句台词后紧跟一个动作或一句推断。女官：行礼带笑 → 递帖子 → 眼睛在她脸上手上转 → 笑 → 凑近 → 直起身。林叁玖：放下东西、跪坐低一些、垂眼 → 小声反问 → 三句真话 → 往后缩 → 冷脸坐直。动作就是她的戏，不加说明。
- **investigation（场景四）· 结果导向：** 每一条提审落在一个结论或对策上；记忆是证词，第 4、5、6 章是她自己的口供，两份对得上才下结论（示范 6）。
- **inner-mono（吐槽两处、提审六）：** 吐槽单独成段、一种手法、点一下就收；提审六两三句推理，用「说明」「意味着」，不写成独白大段。
- **transition（场景一、五、六、七）· 时间衔接：** 每场第一句并进时间（「当天夜里，」「几日后，」「宴那天早上，」），不写空转句，不写过了多久的感慨。
- **pov · 视角分界：** 全章只跟林叁玖；女官、侍女、何皇后只写看得见的和她推断的。
- **prose · 三维编织：** 一句里把「发生了什么—她推出什么—她怎么做」织在一起（侍女通报 + 她听出是谁 + 放下东西），不拆成三句三段；剪指甲、系腰带例外——只织「发生了什么—她怎么做」。
