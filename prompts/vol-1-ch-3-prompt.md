## 任务指示

创作第 1 卷第 3 章正文「汉宫争艳（3）」（在全卷中的角色：压抑段后段——宫规和天赋枷锁一起压到她身上）。

输出文件：`archives/vol-1-ch-3-hangong-zhengyan-3.draft.md`。正文不写章标题，第一行直接进正文。

### 字数与压缩策略
- **目标字数：本章不规定字数。** 不写字数统计，不写 quality_gap。叙事完整优先；永远不为凑字数加内容，默认方向是删。
- **压缩策略：** 写长了优先压低权重部分（¶5 数日后出门），压到一两句完整陈述句即可；不得因压缩删改「约束红线」里的照录台词与情节红线。

本章驱动力：信息驱动（宫里比一场到底怎么比、输了会怎样、她能不能躲）；辅助威胁驱动（何贵人随时可以邀战，她推不得；她被问就只能说真话）。

信息释放节奏：先给答案，再收紧——前半章把规矩一条条交给读者，每条规矩马上落到她身上，越懂越紧（推不得 → 比不过 → 底牌外泄 → 身边的人信不过）。

### 叙事目标
1. **核心悬念：** 上位邀战、下位推不得，何贵人随时能来，她拿什么撑？她的「怕」已经被宫里的人听见，会传到哪里？→ 本章结束时：**加深**（规矩懂了，路更窄了；生死局下位能不能推，只问不答）。
2. **读者情绪（离场感受）：** 压抑里带一点硬——她不信人，只靠交换和抢先提问往前走。
3. **爽点设计：** 信息兑现 + 能力兑现。信息：这个世界比一场的整套规矩，铺垫在 ¶1 她抢着问，释放在 ¶2、¶3（女医说）和 ¶6（起哄者喊）。能力：林叁玖第一次用「抢先提问」对付魔镜真言，铺垫在 ¶1 起手，释放在 ¶9 一句「听明白了吗？」堵回侍女的问话。

### 写作方法论（动笔前按顺序执行）
1. **焦点锁定：** 每个场景只锁一个焦点（见场景原材料「本场景焦点」）。高权重场景（女医上药）写到动作与感知层级，并同时执行下一条感官取舍；低权重部分（数日后出门）快速带过，但仍遵守焦点和感官取舍。
2. **感官分层取舍：** 每个场景以 2 种感官为主，氛围允许时 3 种，其余一笔带过，禁止全维度均匀堆砌。场景一：触觉（药膏凉一下又辣一下）+ 嗅觉（药味）；场景二：视觉（宫墙、廊下、围着的人）+ 听觉（远处的吵嚷、起哄）；场景三：视觉 + 侍女的动作。**声音例外：** 声音线索属于情节红线的关键信息、且以一两句简短白描出现时，不计入感官名额（本章：她一停嘴，屋里只剩药匙刮瓷碗的声音；掖庭一角的吵嚷）；环境装饰音不算例外。
3. **节奏交替：** 一段问答 + 一段推理 + 一个手上动作循环（女医抹药、刮碗、收碗、合药箱穿插在问答之间）；场景二是吵嚷的、起哄声一句接一句，场景三压低声音、慢下来。不连续堆对话，不连续堆推理。
4. **信息释放控制：** 规矩只从女医的回答、起哄者的喊声里出来，一条只说一遍，后面紧跟推理或动作，不连成讲义。机制一律不解释；读者只拿到林叁玖拿到的东西。
5. **结构红线：**
   a. 问答别打成乒乓链：女医那一段问答之间插抹药、刮碗等动作拍和林叁玖的推理，不让一问一答连续超过约 8 拍。
   b. 章首冷开场：第一句就是女医进门或药膏抹上胸口这类动作 / 触感，不用「时间 + 场景状态」开头。
   c. 同一场最多一个结果拿到明确回执：场景三里侍女应「诺」是唯一回执，不另写她办成了什么。
   d. 章尾不总结、不升华、不预告；停在作者定的那句单独成行的结论句上（见红线），前面的句子不为它排证据。

上章结尾画面：林叁玖躺在王美人居所的席子上，胸口乳沟中间红了一片，门外侍女乱成一团喊着快去请女医；她接收了王美人到毒发倒地为止的记忆，接下【通关条件：击败何皇后。】【任务失败：抹杀。】；王美人的怨魂问她「我美吗？」，魔镜真言逼她说了真话；怨魂留下三条遗言化成血字；她感觉到卵巢里的本源核心，系统报【本源核心：4/5】，她哽住了。

## 案例

> 以下案例一至三是写法说明（不得照抄进正文）；案例四是原作 1.txt 原文摘录，只学写法，不照搬内容、句子和称呼。

**案例一·规矩问答：R1 → 遗言第一条 → T1**
林叁玖问得短，问完就等；女医答得短，手上不停（药膏、药匙、瓷碗）。女医答完 R1a，她只追一句「推了呢？」，女医答 R1b。之后不再追问，转进她自己的推理：先单起一行「遗言第一条。」，下一行用「」引原文，再下一段用完整长句把宫规和遗言叠在一起推到她身上（何贵人是贵人、王美人只是美人 → 想什么时候比就什么时候比 → 比不过加推不得，只剩被叫上场一条路），推理用「说明」「意味着」「而」把逻辑摆在明面上；最后用一个看得见的动作收住：视线落回胸口那片红。这一段的情绪是「发沉」，直说一个短语就够，不写盯着不动。（演示：dialogue·动作穿插 + 引规则→推理）

**案例二·「怕。」——强度峰值**
她一停嘴，屋里只剩药匙刮瓷碗的声音——这一句就是女医开口的空当。女医收碗、看她一眼、问。她答「怕。」，一个字，一人一段。紧跟一句无奈：林叁玖咬了咬牙（不用「扇自己嘴巴子」，第 2 章用过）。女医的手顿一下、没接话、低头合药箱、告退，全是看得见的动作，不写女医怎么想。然后才是林叁玖的推断（T3），推断后面直接接情绪那一句（这个天赋在宫里是一副枷锁），同一段或紧挨着，不单独成行。（演示：dialogue·真言约束下的问答 + inner-mono·情绪直说接推断）

**案例三·掖庭一角：用起哄写「这是常事」**
不让任何人解释「宫里起了冲突就比一场」。常事感从围观的人身上出：没人劝架，反倒围上来；起哄声一句接一句，喊得熟练，连「比什么」「打到什么份上」都是旁人替当事人喊出来的。两个宫女当场解开衣带、褪下上衣——写到这里停。林叁玖只看了一眼，转身走，侍女跟上。场景二的推理（T4、T5）放在走开以后，不在围观时写。（演示：group-scene·旁观者推进 + pov·视角分界）

**案例四·原作 1.txt 原文示范（原样摘录，只学写法）**

#### 三、T1 句式 / 认知动词 / 感官取舍

**作者覆盖（优先于下面的清单）：**「倒吸一口凉气」可以用，一章一两次以内；「像」「仿佛」「如同」混着用，不刻意禁止；拟声词和口语化的重复描写不算 AI 味；情绪标签、心理说明、动作来由解释、比喻、总结句可以写。

**T1 最毒句式（出现即换）：**
- 「不是 A，（而）是 B」及其变形（并非……而是、与其说……不如说、你以为……其实、看似……实则）→ 直接写 B。
- 「……，带着一丝……」万能状语 → 拆开或换动作。
- 「当……的时候」起句 → 拆成独立动作句。
- 「她意识到 / 她注意到 / 她发现」这类认知动词前置 → 删掉，直接写事实。
- 「与此同时」→ 直接换场景。
- 元叙事：不写「本章」「下一章」，不写「此时的她还不知道……」这类全知句。

**作者点名的 AI 腔（同类句式都不要写）：** 碎句定格、动作三连拍、描写系统字样、机械套句式、自造对称俏皮句、藏关键词的谜语断句——原句与原作写法见「写作规范·原作不会出现的写法」对照表。

#### 五、写作规范（本章全部按非性斗章写）

**叙事身份：** 一个脑子转得快、嘴上不饶人的讲述者，贴着林叁玖一个人讲：她看到什么、想到什么、推出什么，就平平实实地说出来。句子完整，逻辑写在明面上；情绪直说一句就走；不摆镜头，不做定格，不玩对称句。

**硬约束：**
1. 视角只跟林叁玖；女医、侍女、宫女的心思只写成她的推断。
2. 一句一段为主；叙述句写成完整的一句：一件事的前因后果放在同一句里，逗号连两到四个分句，一般二三十字到四十字。不用句号把一个意思切成三四截。
3. 单独成段的短句只用在三处：吐槽句、反应句、结论句（章末那句）。
4. 一个事实只说一遍，说完马上接推论或下一步动作，不换个说法再说；前面已有的动作、声音不重复写。
5. 吐槽不加引号、不加「心里想着」，直接写进叙述。顺序：触发 → 一句吐槽单独成段 → 一句反应 → 零到三句展开 → 一句收回剧情；一处只用一种手法；对准外面的东西（宫规、对方的话），不自己造对称俏皮句。本章章纲没有安排吐槽，**最多写一处**，写了就列进新增清单。
6. 比喻串本章不用。
7. 网络口语、自嘲只作点缀，一句最多一个。
8. 情绪直说：一个短分句点名情绪，再接推理或动作（「想到这儿，……」「正这么想着，……」）；不用盯着不动、半天没挪开这类定格暗示情绪。
9. 对话一人一段，台词短（十几个字以内）；台词后紧跟一句叙述，交代为什么这么说或说完的后果；对白用 “ ”。魔镜真言逼出真话后跟一句无奈（「怕。」之后）；「信不过。」之后不后悔。
10. 遗言引用：「遗言第几条。」单起一行 → 下一行「」引原文 → 下一段推理或动作（格式见约束红线第 11 条）。
11. 原书天赋名用「」（如「魔镜真言」）。
12. 回忆、前情用完整陈述句直说，不写藏关键词的谜语短句，不为顿挫在句中硬加逗号。

**作者的去 AI 味口味：**
- 台词越短越像人话：删把话说满的限定语和凑词的尾巴（例：「除非事先说好打到本源核心耗尽，那才是要命的局」→「除非本源核心耗尽，那才是要命」）。林叁玖自拟的问话、¶9 她交代差事的话都按这个口味写。
- 一件事只说一遍；前面已有的提示音、动作不重复写。
- 不写自造对称俏皮句、机械套句式、藏关键词的谜语句。

**减法：** 情绪标签、心理说明、动作来由解释可以写；比喻、总结句不删。仍避免：设定复述（动作中提醒人物卡属性）、精确数字、冗余头衔、技术/临床词、回指上一章的解释（不重讲永巷那一场、不重讲怨魂）、资料卡、单独成行的强调句（吐槽、反应、结论短句除外）、解释性台词、机制解释。「毕竟……」全章最多一处。

**描写层次和手法：**
1. 一句的三种骨架：场景 + 动作 + 心理落点；事实 + 转折 + 结论（T1、T2 用这个）；动作链带目的（每个动作都在推进位置或带目的，如侍女披衣、扶人、在前头引路）。
2. 从动作到心理用短引子过渡：「想到这儿，……」「正这么想着，……」；或同一句里动作在前、心理落点在后。
3. 心理的主体是推理：用「说明」「意味着」「难不成」推进，规矩原文 → 这意味着什么 → 落到她身上。
4. 魔镜真言的问答节奏：对方提问 → 被迫实话 → 一句无奈（或这次不后悔的一句）。
5. 抢先提问的节奏（示范 3）：她先开口 / 堵回去 → 一句交代她为什么这么做（只在 ¶1 交代一次，¶9 不再解释）。

### 场景写作指引

本章涉及 3 种场景类型（dialogue / group-scene / inner-mono），另始终加载 pov、prose 各 1 条。

- **dialogue · [动作] 动作穿插（女医上药）：** 女医的回答都夹在上药的手上动作里——抹药、刮碗、收碗、合药箱，一个动作配一条规矩，不让纯问答连成一串；林叁玖是躺着被上药的人，她能做的只有问和看，所以她这边的「动作」是视线（落回胸口那片红）和停嘴。情绪是从冷静试探往下沉，她的问话越来越短（从「能不能推」到「输了就得死？」），停嘴那一下就是女医开口的空当。
- **dialogue · [身份] 身份化语言（女医、侍女）：** 下人对美人说话守规矩：称「美人」，侍女自称「奴婢」，话短，不直呼何贵人以外的人；林叁玖用主子的口气说话，短、直、不客套，但不起高调——她是骗子，不是真主子，要的只是话头。
- **group-scene · 旁观者推进（掖庭一角）：** 起哄的人替当事人把约定喊出来（比什么、打到什么份上、核心归谁），当事人只负责吵和解衣；林叁玖和侍女站在圈外，镜头不进圈里。
- **inner-mono · 情绪直说接推断（「怕。」之后、掖庭之后）：** 两处各用一个情绪短语 + 一段推理，不用思维碎片，不写崩溃；林叁玖越冷，压抑越沉。
- **pov · 视角分界：** 全章只在林叁玖脑子里；女医、侍女的反应只写看得见的（手顿一下、愣住、脚下停半步），推断用「说明」「极有可能」，不写「她心想」。
- **prose · 三维编织：** 一句里把「发生了什么—她感到什么—她怎么做」织在一起（药膏凉一下又辣一下 + 药味冲鼻 + 她不等女医开口先问），不拆成三句三段。
