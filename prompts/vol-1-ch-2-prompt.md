# 第 1 卷第 2 章 提示词

## 角色

你是一个悬疑脑洞题材（穿书 + 无限流）小说作家。这本书的世界里，人们遇到冲突的第一反应是性斗，而且性斗会死人。本章不是性斗章。

---

## 任务指示

创作第 2 章正文（在全卷中的角色：绝境入场、立处境。卷里第一个状态转折落在本章：系统任务弹出，失败即抹杀，她被绑上唯一一条活路）。上一章停在【剧情世界：汉宫争艳，载入中。】。

### 字数与压缩策略
- **目标字数**：2000–2500 字。**这是软指标**：叙事完整优先，不为凑字数加内容；写短了就在产出末尾如实报告实际字数。
- **压缩策略**：超出上限时，先压低权重的场景一，再压中权重的场景二里「宋皇后被废 → 王甫被诛 → 立后」那一串（可压到每件事半句）。压缩不得删改红线内容，不得动场景三的提示原文与场景四的数核心、章末吐槽。

本章驱动力：悬疑驱动，辅以威胁驱动。林叁玖记得接下来几个月会发生的事 ↦ 何贵人不知道王美人换了人；何贵人知道宴席上的毒怎么下 ↦ 林叁玖只记得王美人一口菜没动，还是死在了宴后。
信息释放节奏：前半章回答「她是谁、这里发生过什么」，后半章一层一层加码：身上的伤 → 死期 → 失败抹杀 → 三行遗言 → 只剩 4/5。章末留钩子，不收。

叙事目标：
1. 核心悬念：一个只剩四颗本源核心、失败就抹杀的人，拿什么赢一个连王美人都碾过去的何贵人？王美人一口菜没吃，为什么还是死了？→ 本章结束时：**加深**（从「她会进到谁身上」转成「她怎么活过那场宴」）。
2. 读者情绪：压着，最后一口冷嘲。席子上，胸口还在疼，一行【本源核心：4/5】，她在心里自嘲刚进来就少了一颗命。
3. 爽点设计：期待落差。铺垫于场景一、场景二（读者等她进去以后是谁），释放于场景三、场景四：答案是一个刚输、会死、只剩 4 颗的人；落点是章末那段吐槽。

写作方法论（动笔前按以下顺序执行）：
1. 焦点锁定：对每一场景，识别其唯一的「核心冲突」或「人物情绪」或「信息差」（三选一，不叠加）。全文 70% 笔墨集中于此焦点对象；次要环境、路人、背景一律简笔带过。禁止同等篇幅刻画所有元素。高权重场景细化到动作与感知层级，且必须同时应用「感官分层取舍」规则；低权重场景允许快速转场，但不得违反焦点锁定或感官分层取舍规则。
2. 感官分层取舍：以 2 种感官为主进行细化，氛围允许时增至 3 种，剩余感官一笔略写。避免全维度均匀堆砌。**声音例外：声音线索属于本章情节红线的关键信息、且以简短白描（1–2 句）呈现时，可不计入感官名额**（本章的例外只有两处：门外侍女乱成一团、喊着找女医；脑子里那一声「叮」）；环境装饰音不属于例外。
3. 叙事节奏交替：一段密集动作/信息 + 一段短心理留白 + 一句轻环境过渡循环。禁止连续长描写、通篇等长段落。
4. 信息释放控制：记忆拆成碎片带出，一段比一段快，不一次性完整交代。允许留白，不把设定、心理全部写透。
5. 结构红线：
   a. 章首冷开场：第一句直接落在她身下的席子或胸口的疼上，不用「时间标记 + 场景状态」式开头。
   b. 同一场最多一个结果拿到明确回执（本章的回执只有一个：【本源核心：4/5】）。
   c. 禁证明链：记忆碎片不连续摆证据，不在段尾盖章「原来她是被害死的」。
   d. 章尾禁总结、升华、预告。

## 背景信息

### 前情上下文

上章结尾画面：雨还砸在透明伞面上，她手里攥着伞，眼前一黑，雨声一下子全没了，只剩一行【剧情世界：汉宫争艳，载入中。】。

读者情绪残留：悬。

上章留下的缺口：「汉宫争艳」是哪儿，她会醒在谁身上，那个被问就只能说真话的天赋进去以后怎么办。

### 作者偏好记忆

- 「写手补的感官细节全部保留，一点都不多余」→ 贴着林叁玖视角补的小感官细节可以写，不当冗余；但凡提示词场景原材料里没有的具体物件、感官细节，写完都要列进产出末尾的清单。
- 「林叁玖的语言风格要和原作几乎一样；吐槽要更丰富」→ 吐槽口语、网络化、带自嘲、爱反问，可以展开成几句，不只留一句干巴巴的评语。口吻示范见「案例」一节。
- 「时长、小动作、重复句前后要对得上」→ 手里、身上已有的东西不再「拿起」；同一句描写不在相邻段重复。

### 角色初始状态

**林叁玖**（本章唯一视角人物，身体是王美人的）：
  起点：从雨里眼前一黑，再睁眼躺在一张席子上，胸口火辣辣地疼，门外乱成一团。她躺着没动，先听、先看。
  → 经历：别人的一辈子一段段挤进脑子，从永巷那一场一直翻到自己在回宫路上倒地；手按上胸口那片红，疼对上了。提示一行一行砸下来：白雪、系统任务、失败抹杀；又浮出三行带着怨气的字，她从头到尾看一遍，记住了。
  → 终点：撑起身子，看清这具身体，数出小腹深处只剩四颗本源核心，【本源核心：4/5】；她用一段冷嘲收住。
  本章微习惯/小动作：出事先不出声，躺着听、睁眼看；手按胸口对疼；看东西看一遍就记住；心里吐槽多，嘴上一个字不说（本章她一句台词都没有）。

**何贵人 / 何皇后**（只在记忆碎片里）：
  印象：站着、俯视，赢了就把话撂下。
  本章必须完成的一件事：邀王美人「去永巷观水」；赢完俯视着她撂下一句「从今往后要知道，谁才是这里的主人。」；后来立后，成了何皇后，请她赴长秋宫宴。

**宋皇后、王甫**（只在记忆碎片里，各一笔）：宋皇后被废；王甫被诛。

**门外的侍女**（只闻其声，不进门，不起名）：脚步乱成一团，喊着找女医。不跟林叁玖说话，林叁玖也不应声。

## 案例

以下示范只演示写法，不必照抄；示范里出现的东西都在本章场景原材料之内。

**案例一｜场景一，醒来**
她上一刻还在雨里，下一刻躺在一张陌生的席子上。醒来的换场不靠「当她再次醒来时」，靠感官前后一换：雨声、伞柄没了，身下是席子，胸口是疼；门外的乱只用耳朵听。情绪是懵，句子可以长一点，一口气串下来，最后落在她没动。
> 身下是一张席子，头顶也不是写字楼里亮得晃眼的灯，胸口火辣辣地疼，疼得林叁玖连气都不敢吸满，门外脚步乱成一团，有人喊着快去请女医。林叁玖躺着没动。
（演示：五感反差·触觉 + 听觉）

**案例二｜场景二，疼对上了**
记忆里的乳斗只给一句台词，不写过程；把记忆和眼下接起来的是一个物件：胸口那片红。信息差在这一刻翻过来：她开始知道别人不知道的事。情绪往下沉，句子放短。
> 林叁玖的手按上胸口，按在那片红上，疼得一抽。对上了，就是刚才那一场。
（演示：物件线索·胸口红印串起记忆与眼下）

**案例三｜场景四，看这具身体**
不让她「站定照镜子」，身材跟着撑起身子、低头这两个动作露出来；只抓一个锚点放大：乳房；腰、臀一笔带过。
> 林叁玖撑着席子坐起来，低头，胸前那一对比原身还要大一圈，一动就扯着疼……
（演示：外貌锚点 + 动态外貌化）

**吐槽口吻示范**（照这个腔调写，不照抄句子；句子里的内容必须是本章已经发生的事）
- 「不是，这……还带这样的？」——对着硬塞过来的东西先来一句质问。
- 「等等，……？」——察觉哪里不对，短短一个反问顶上来。
- 「好消息：……。坏消息：……。」——先给一个聊胜于无的，再给一个要命的（比如：好消息还剩四颗，坏消息本来有五颗）。
- 「这跟……有什么两样？」——拿日常里的倒霉事打比方，一串两三个。
- 「……恨不得……」——夸张地自嘲，骂自己或者骂这破运气。
- 「狗屁……」——一个粗口，点到即止。
- 上一章用过的「……就这？」本章不再用。

## 输入

### 场景原材料

**场景一｜席子上·醒来｜懵｜权重：低**
  入口情绪：悬
  核心事件：睁眼 → 身下是席子，头顶不是写字楼的灯 → 胸口火辣辣地疼 → 低头：乳沟中间红了一片，乳头还在抖 → 门外脚步乱成一团，侍女喊着找女医 → 她躺着没动，不应声
  情绪意义：她被扔进一具刚挨过打的身体里，外头一片乱，没人知道里头换了人。
  信息差：门外的侍女知道王美人刚输了、伤得不轻 ↦ 不知道这具身体里换了人；林叁玖此刻连自己是谁都不知道 ↦ 读者一样。
  情绪拐点：悬 → 懵。
  感官：触觉（席子、胸口的疼）+ 听觉（门外的乱，属声音例外）。
  → 衔接：还没弄清在哪，记忆先挤了进来。
  本场景焦点：人物情绪
  本场景权重：低（这里的「低」指不铺环境、快速切进身体感知，约 200 字内，不必压到 100 字）

**场景二｜记忆·从永巷到倒地｜懵 → 沉｜权重：中**
  入口情绪：懵
  核心事件：记忆一段段往脑子里挤，这次是别人的一辈子 → 何贵人邀她「去永巷观水」→ 乳斗惨败，只剩碎片：何贵人俯视着她：「从今往后要知道，谁才是这里的主人。」→ 她的手按上胸口那片红，疼对上了 → 碎片接着往下翻，一段比一段快：宋皇后被废 → 王甫被诛 → 何贵人立后，成了何皇后 → 长秋宫宴：一口菜没动 → 回宫路上天旋地转，倒地 → 记忆到这里断了 → 她躺在席子上，胸口起伏，对上了时间：这些事都还没发生，最后倒地那一下就是这具身体的死期
  情绪意义：她还没看清这个地方，就先知道了自己几个月后会死在哪一天。
  信息差：林叁玖记得接下来几个月会发生的事 ↦ 何贵人不知道王美人换了人；何贵人知道宴席的毒怎么下 ↦ 林叁玖只记得王美人一口菜没动，也死了。
  情绪拐点：懵 → 沉（记忆断在倒地那一下）。
  感官：触觉（手按胸口的疼）+ 视觉（碎片画面）。
  → 衔接：她还躺着喘，脑子里「叮」一声。
  本场景焦点：信息差
  本场景权重：中

**场景三｜提示·任务与遗言｜沉 → 压｜权重：高**
  入口情绪：沉
  核心事件：脑子里「叮」一声 → 进剧情世界提示两行 → 她对白雪的反应（三句，照录）→ 系统任务四行一行一行弹出来 → 她盯着最后一行，门外的喊声还没停 → 脑子里又浮出三行字，带着怨气（可以用「血字」这类意象），三条各自单独一行 → 她把三行字从头到尾看了一遍，记住了
  情绪意义：通关的唯一办法，是让那个把王美人碾在地上的人核心耗尽；而死人留给她的第一句话就是「你都比不过她」。
  信息差：读者和林叁玖同步拿到任务、失败抹杀和三行遗言 ↦ 宫里所有人都不知道。
  情绪拐点：沉 → 压，峰值在【任务失败：抹杀。】弹出那一下。
  感官：视觉（一行行的字）+ 听觉（「叮」、门外的喊声还没停，均属声音例外）。
  → 衔接：三行字记下了，她撑起身子。
  本场景焦点：人物情绪
  本场景权重：高

**场景四｜低头·4/5｜压 → 冷嘲｜权重：高**
  入口情绪：压
  核心事件：她撑起身子，低头看这具身体：乳房比原身还要大一圈，腰、臀一笔带过 → 她冥冥之中感觉到小腹深处、卵巢里的本源核心，一颗一颗，数得出来 → 数完，系统弹出【本源核心：4/5】→ 她的吐槽：刚进来就少了一颗命（可用「好消息 / 坏消息」句式，展开成几句）→ 全章停在吐槽上
  情绪意义：她手里剩的东西，数得清清楚楚，少了一颗。
  信息差：林叁玖知道自己剩四颗、知道死期和任务 ↦ 不知道王美人是怎么被毒死的。
  情绪拐点：压 → 冷嘲（数完那一下）。
  出口情绪：压着的冷嘲
  感官：视觉（低头看身体）+ 触觉（撑起身子、胸口还疼）；小腹深处那一下是她冥冥之中的感觉，不写成对机制的解释。
  本场景焦点：人物情绪
  本场景权重：高

### 提示与台词原文（逐字照录，每条单独成行）

```
【叮，恭喜试炼者成功进入剧情世界，依靠魔镜真言，你将知道世界上最美丽的女人是谁。】
【世界上最美丽的女人是白雪。】
```
紧接着的白雪反应（三句，逐字照录，不加引号，各句之间可以分段，写完就过，不做任何推测）：
```
这还用你说？
林叁玖嘴角一抽，暗骂这种耳熟能详的童话公主故事谁没听过？
三岁小孩都知道的答案，用天赋再跟她强调一遍？
```
然后系统任务：
```
【剧情世界：汉宫争艳】
【你已进入王美人的身体。】
【通关条件：在性斗中，令何皇后的本源核心耗尽。】
【任务失败：抹杀。】
```
三行遗言（不用【】，不加序号，每行单独成行）：
```
她邀你比什么，你都比不过她。
不要相信任何一个说要帮你的人。
长秋宫的东西，一口都不要碰。
```
数完核心后：
```
【本源核心：4/5】
```

## 输出

### 不可违反规则

**优先级（从高到低）：** ① 约束红线 → ② 字数 → ③ T1 词 / 认知动词 / 感官 → ④ 叙事规则 → ⑤ 写作规范其他规则。**红线内容不可压缩、不可删减**；叙事规则高于同层写作规范的其他规则，但低于①–③。

#### ① 约束红线

冲突阶梯：卷阶梯第 1 层（绝境入场）。本章只建立处境，不涉及对决。章内小阶梯：身体受伤 → 知道死期 → 被绑上任务（失败抹杀，对手正是碾过王美人的人，遗言说比什么都比不过她）→ 命少了一颗（4/5）。

情节红线（不可删减）：
1. 「提示与台词原文」里的每一行逐字照录，顺序按场景一至四；【】只给系统提示。
2. 白雪那三句照录后就过，不做推测；这三句里的「三岁小孩」是全章唯一允许出现的「岁」和「小孩」。
3. 本源核心：她冥冥之中感觉到小腹深处、卵巢里的本源核心，一颗一颗数得出来，**数完**系统才弹【本源核心：4/5】；「本源核心」用全称。

#### ⑤ 写作规范其他规则

**网文风格基线**
1. 全程线性叙事（记忆碎片是唯一一次倒回去，翻完就回到席子上）。
2. 拒绝完美叙事，允许留白和思绪跳跃。
3. 禁止刻意堆砌技法。
4. 禁止诗词腔（宫里的场景也不写成古风文案）。

**写作风格约束（本章非性斗章：只取句法与写法，不取性斗基调、性斗例句和样本的句式数值）**

【叙事身份】第三人称，镜头跟在林叁玖身后，只拍她看得见、听得见、想得到、疼得着的东西。叙述语气直，不装文雅。叙述者可以顺口点评一句「毕竟……」，本章最多一处，只点评眼前的事，不交代身份、履历、机制。

【词汇】偏爱用词：直接、一把、猛地、使劲、狠狠、彻底。动作动词为主，心理动词少量，动词力度强。

【句式】叙述句可以用逗号把一串动作连成一口气的长句，短句留给吐槽和最压的几处（抹杀那一下、数完那一下）。本章不按性斗样本的句长、感叹句比例验收。

【节奏】本章几乎没有对话：动作与身体感知为主，记忆碎片与系统提示次之，吐槽穿插，环境很少。

【修辞与感官】比喻少，吐槽里可以有一串打比方；比喻引导词「像/仿佛/如同」混着用。全书常态是触觉最多；本章各场景的感官以场景原材料标注的为准。

【情绪表达】先落在身体上（胸口起伏、手按着那片红、盯着字不动），直接点名情绪、心理说明、动作来由可以跟在后面写。

【衔接】连词少，段落靠动作衔接；记忆碎片之间可以直接跳，不用「接着」「然后」。

【视角】第三人称，本章只跟林叁玖（见红线·角色禁区）。

【硬性规则】
- 称呼以「林叁玖」全名为主，同一段里反复用名字，少用她。
- 台词和动作写在同一段：台词在前，紧跟说话人的名字和一串动作。（本章唯一的台词是记忆里何贵人那句。）
- 林叁玖的吐槽不加引号、不加「心里想着」，直接写进叙述，可以用第三人称「她」。
- 拟声词单独成段或放在台词里，不用「传来一声……」这类转述。

【AI 易犯错误（本章适用的）】
- 用「传来一声」「响起一阵」概述声音——直接写声音本身。
- 句子切得太碎、一句一段——见【句式】。
- 照搬样本里的错别字和「的/地/得」混用。

【描写层次和手法（本章适用的）】
1. **动作链长句**：醒来那一段、撑起身子低头那一段，一个主语带一串动作，逗号连到底，落在疼或一个判断上。
2. **看得见的胜负记号**：乳斗的输赢只落在她胸口那片红和还在抖的乳头上。

### 场景写作指引

本章涉及 3 种场景类型（environment / transition / inner-mono），另触发外貌描写，每类 1–2 条。

- **environment · 器物表意（场景一）**：王美人的居所不铺陈，屋里的东西最多一两样，而且只出现在她躺着能看到、能摸到的范围里；席子是唯一必须写的。门外的侍女不知道里头换了人，林叁玖也不打算让她们知道，所以门外只用耳朵听，她不起身、不应声。情绪是懵，句子一口气串下来，末尾落在「没动」。
- **transition · 五感反差（从上一章切到场景一）**：从雨里切到席子上，不写「当她再次醒来时」，用触觉和听觉一换就行：雨声、伞柄没了，是席子和疼、门外的喊。最多两三种感官，不堆。
- **transition · 物件线索（场景二）**：胸口那片红把记忆和眼下串起来：记忆里何贵人俯视、撂下那句话；眼下她的手按上那片红，疼得一抽。信息差就在这一下翻过来。之后记忆快进，一段比一段快，断在倒地。
- **inner-mono · 生理通感（场景二末、三、四）**：死期、抹杀、4/5 三处用身体扛着，压抑段不写「她很害怕」这类直给。冷嘲只在数完核心之后放开，不提前冲淡「抹杀」那一下。
- **appearance · 锚点 + 动态（场景四）**：看身体跟着撑起身子、低头两个动作走，只放大乳房这一个锚点，腰、臀一笔。脸看不见，不写脸。
- **prose · 长短句**：醒来、撑起身子两处用长句一口气串；「任务失败：抹杀」之后、数完核心那一下用短句顿住。
- **pov · 视角分界**：记忆碎片是林叁玖脑子里的画面，何贵人只有动作和那句台词，不写何贵人怎么想；门外的侍女只有声音。
