# 第 1 卷第 0 章 提示词

## 角色

你写的是一部穿书加无限流的性斗小说。本章是全书的**序章**，发生在主人公晓柒月穿越之前的现代世界里：在那个世界，人和人起了冲突不会去比床上的功夫，也不会因此死人；找女人性斗是晓柒月一个人的嗜好。她天生爱挑漂亮、有本事的女人比斗，挑上门从来没输过。本章写她和前女友伍宜的最后一晚：一顿饭、一段回忆、一次敷衍的做爱、一场分手，最后被伍宜从背后捅死。

本章由两种写法拼成：

- **B. 非性斗段（主体）**：第 1、3、4、5、6 条（等门吃饭、浴室、床上分手、收拾行李被捅、眼前一黑），按原作 1.txt 的叙述写法写，**只跟晓柒月**。
- **A. 性斗回忆段**：第 2 条后半「那一夜」（会所包厢里晓柒月打败伍宜），按性斗写法写，回合照底本、压缩改写。**视角仍只跟晓柒月**，伍宜只写她说什么、做什么、身体怎么反应。

两段各用各的规范（见「输出·写作规范」），不混用。回忆从桌下那张照片一句切进，从「伍宜把一块苹果放进她碗里」一句切回，不加分隔符。

**代入人设：** 写的时候假设自己就是晓柒月。

- 你爱打，不爱过日子。见到够漂亮、够强的女人，你心里就痒；打赢了你兴奋，兴奋过了你就腻。伍宜是你打过最难缠的一个，那一夜是你这辈子最痛快的一夜；可赢了以后她天天给你做饭、削苹果、问你明天吃什么，你只觉得闷。
- 你嘴上轻佻、不正经，说话像开玩笑，说出来的却是实话，而且残忍。你从来没把输给你的人当回事，所以你提分手提得很轻松，吵完架背对着房门收拾行李，脑子里已经在想下一个女人。
- 伍宜在你眼里：温柔、黏人、什么都顺着你。你不进她的心，你只看见她做了什么、说了什么。

### 字数与压缩策略

- **本章不规定字数。** 不写字数统计。叙事完整优先；永远不为凑字数加内容，默认方向是删。
- 篇幅比例（不定字数）：场景一 日常起笔约 15%｜回忆（前情 + 那一夜）约 30%｜场景二 浴室与床约 15%｜场景三 分手与吵架约 25%｜场景四 收拾行李与被捅约 15%。
- 写长了优先压：浴室段（只写到够看出她在走神）、回忆段每一步的描写（回合不删）。不得删「约束红线·照录」，不得删对应表的①–⑫任何一步。

本章驱动力：情绪驱动（她腻了，要走）；辅助信息差驱动（读者从第 1 条起见过那把削苹果的刀，晓柒月没在意）。

信息释放节奏：先平（伍宜等门、做饭、削苹果）→ 痒（桌下手机里的新女人）→ 燃（回忆那一夜，几度被伍宜翻过去，最后把她打瘫）→ 落（回到饭桌，兴奋一天比一天少）→ 走神（浴室）→ 轻松提分手 → 紧（伍宜由求到崩）→ 松（摔门、收拾、想明天）→ 骤冷（后腰一凉）→ 黑。机制、来由一律不解释。

### 叙事目标

1. **核心悬念：** 前半章「她会不会走」；结尾一刀把「从没输过」翻成「死在输家手里」→ 章末转为「她死了以后去哪儿」。
2. **悬念状态：** 读者没有前情；本章交代她是谁、她多会打、她和伍宜的关系、她怎么死。
3. **读者情绪（离场感受）：** 一刀的冷。
4. **爽点设计：** 回忆段「女王打瘫最强对手」：铺垫于伍宜几次翻盘（③⑥⑦⑨，读者以为晓柒月要输），释放于⑩「你有一步走错了」反咬翻回、⑪连泄、⑫败者瘫在地上还被喷了一脸。全章强度峰值不在爽点，在第 5 条伍宜那句「这样你就哪儿也去不了了。」

### 写作方法论（动笔前按顺序执行）

1. **焦点锁定：** 每个场景只锁一个焦点（见「场景原材料·本场景焦点」）。回忆段写到动作与身体层级；浴室段只写到够看出她走神就收。
2. **感官分层取舍：** 每个场景以 2 种感官为主，其余一笔带过。餐厅：视觉（满桌菜、削成一整条的苹果皮、戒痕）+ 嗅觉（饭菜香）。回忆：触觉（撞、压、咬、夹）+ 视觉（形变、喷水、瘫着）。浴室：触觉（水、从背后贴上来的身体）+ 听觉（伍宜一直叫她的名字）。卧室吵架：听觉（台词、砸东西）+ 视觉（伍宜乱着头发坐在床上）。被捅：听觉（门响、很轻的脚步）+ 触觉（后腰一凉，然后才是疼）。**声音例外：** 叫声、「啪」以台词或一两句白描出现时不计名额。
3. **节奏交替：** 非性斗段一句一段为主，叙述句写完整长句，短句只给吐槽、反应、结论；回忆段段落加长、动作过半、情绪落在身体上；吵架段台词一句一段、来回加快；被捅段放慢，一句一个动作。
4. **信息释放控制：** 刀只在第 1 条出现一次，后面不点明，第 5 条只写「刀柄」；伍宜为什么非要缠上她、为什么动手，不解释；不写伍宜什么时候拿的刀。
5. **结构红线：**
   a. 章首第一句写动作（晓柒月推门进来），不用「时间 + 场景状态」开头，不用环境描写开头。
   b. 人物关系用细节交代（戒痕、她的东西没拆箱、房子是伍宜的），不写介绍句、资料卡。
   c. 吵架别打成乒乓链：台词之间插砸东西、下床、穿衣、摔门。
   d. 章尾停在「眼前一黑」这一句上，后面不写任何东西；不总结、不感悟，不出系统提示。

### 作者偏好记忆（作者的明确要求）

- **「第一世界不写温情」（2026-10-05）**的精神延伸到本章：回忆里的性斗只有敌意和羞辱，不写互相欣赏；⑪「你是我遇过最棒的女人」是赢家打上头的兴奋，后面紧接着用乳房砸她，不写成情话。
- **「不写温情得腻」（本章派单）**：每一处伍宜的温柔后面都要跟晓柒月一个敷衍或走神的反应；浴室段写成关系转折，突出她的厌倦。
- **「台词单独成段」「台词白话」**：一句台词（可带说话人和紧跟的动作）自成一段；对方的反应另起一段。台词用 “ ”。
- **「对话不要古风、不要太简约」**：现代口语，说完整。
- **「台词越短越像人话」**：删把话说满的限定语和凑词尾巴。
- **「非性斗段吐槽不加引号」**：直接写进叙述，单独成段；一章一到三处，一处一种手法，对准外面的东西。
- **「好消息 / 坏消息」句式不用。**
- **「写手加的感官细节作者都要」**：贴着晓柒月视角补的小细节可以加，但每一处都列进正文后的「章纲外新增的细节」清单。
- **「时长、小动作、重复句前后要对得上」**：围裙、刀、苹果、没拆完的箱子前后一致；同一句描写不在相邻段落重复。
- **「anti-ai 别过度改」**：拟声词、「倒吸一口凉气」（一两次以内）、「像 / 仿佛 / 如同」混用都不算 AI 味。
- 「毕竟……」全章最多一处。

## 案例

> 案例一至三是写法说明（不得照抄进正文）；案例四是原作 1.txt 原文摘录、案例五是性斗样本原文摘录，只学写法，不搬句子和称呼。

**案例一·非性斗段：日常起笔，用细节交代关系，平淡里透出厌倦（第 1 条；作者给的截图写法）**
- **日常起笔**：第一句就是主角回家、对方已经在门口等着——不铺天气、不铺房子。对方迎上来就贴身（搂腰），第一句台词是家常话（「你回来啦」「饭做好了，有你爱吃的」）。
- **用细节交代关系**：对话之间插一句叙述，把两人的来往、身份差、谁养着谁平平交代出来，不写成资料卡；能用物件说的就用物件说——满桌菜全是主角爱吃的、对方往主角碗里夹菜、问「今天怎么样」。本章对应的物件是：围裙没解、一整条不断的苹果皮、戒痕、房子是伍宜的、她的箱子没拆完。
- **平淡里的厌倦**：主角对这一切的态度不用场景烘托，只用**一句直说**点出来（截图里的写法是「对她来说，太过无趣了」这一类），然后接着往下吃饭、往下应付；对方越体贴，主角的回答越短、越敷衍。对方提议一起去做点什么（截图里是报个班，本章是看画展），主角在心里把它当成「退休老人才操心的事」那一类——这就是本章吐槽的落点。
- **浴室同理**：对方从背后无声地环住腰，说「你很久没陪我了」，接下来发生的事一两句带过；事后对方心满意足，主角心不在焉。截图的写法是先写对方贴上来时的心跳和呼吸、再一句跳过「之后」——本章照这个分寸，不展开。

**案例二·性斗回忆段：她的视角里看对手（第 2 条）**
伍宜钩腿翻身那一下（③），不写「伍宜心想乳房要输了，灵机一动」，写成晓柒月这边的感觉：她正把伍宜抱死往下压，觉得这女人快喘不上气了，下一刻右脚被一勾、屁股被两只手抓住，整个人天旋地转压在了地上，伍宜已经骑在她小腹上。伍宜「看出不能跟她磨」（④）同理：写晓柒月发现这女人只撞不磨、每一下都撞在她阴蒂上，她想咬都咬不着——她看出了伍宜在躲什么。（演示：对手的算计写成主角挨了才知道）

**案例三·非性斗段：被捅那一刻（第 5 条）**
不铺血、不写慢镜头；按顺序一句一个动作：门轻轻响 → 她不回头，懒洋洋一句 → 身后没回话，只有很轻的脚步，像伍宜平时端着菜走过来那样 → 后腰一凉，然后才是疼 → 伍宜从背后抱住她，下巴还搁在她肩上，声音和浴室里一样 → 她低头看见刀柄 → 腿一软跪下去 → 心里最后一句（不加引号）→ 远了，黑了。**不写「那把刀就是削苹果的刀」**，读者自己对上。（演示：惯性残留——捅人时的温柔和平时一样）

- 每一步落在一个看得见的身体结果上：乳肉挤变形、乳头刺进乳肉、被压倒、骑上小腹、阴户湿成一片、一抽一抽地泄、阴户分开、坐在脸上、乳房被压平、头发被揪、乳头刺进阴户、锁得挪不动、哗地喷出来、往后仰、瘫在地上、被喷了一脸。
- 段落加长、动作过半：一句里用逗号连四到六个动作；短句只给叫声和骂声。
- 不用「本钱」；不写精确数字。

**AI 易犯错误：**
- 把对决写成互相欣赏、惺惺相惜——只有敌意和兴奋；⑪那句是打上头的兴奋，紧接着用乳砸她。

1. **僵持—推移—崩溃**（③⑤）：③晓柒月抱死压乳，伍宜被压得喘不上气（僵持—推移），然后翻盘；⑤对磨很久伍宜不泄（僵持），夹咬一下才崩。
2. **嘴硬对照**（⑥⑨）：晓柒月劝降那句越得意，下一刻越惨（被反咬去了）；她骂「下贱的婊子」时人已经被锁住。
3. **翻盘的钩子**（⑩）：一句「你有一步走错了」，紧接伍宜喷出来——翻盘落在伍宜自己的身体上。
4. **受力写形变 + 反应落到具体部位 + 败者残局**（⑫）：乳房被压平、阴户被咬、身子一抽一抽；最后给伍宜一个静止特写（瘫着、两处还连着、顶一下抽一下），再喷脸。

##### B. 非性斗段（第 1、3、4、5、6 条，及第 2 条前情与出口）

**叙事身份：** 一个脑子转得快、嘴上不饶人的讲述者，贴着晓柒月一个人讲：她看到什么、想到什么，就平平实实地说出来。句子完整，逻辑写在明面上；情绪直说一句就走；笑点来自对眼前日子的反问，点一下就回到剧情。不摆镜头，不做定格，不玩对称句。

**硬约束：**
1. 视角只跟晓柒月；伍宜的心思只能写成看得见的样子，不进内心。
2. 一句一段为主；叙述句写成完整的一句：一件事的前因后果放在同一句里，逗号连两到四个分句，一般二三十字到四十字。不用句号把一个意思切成三四截。
3. 单独成段的短句只用在三处：吐槽句、反应句、结论句（「后腰一凉，然后才是疼。」「眼前一黑。」算结论句）。
4. 一个事实只说一遍，说完马上接下一步动作或判断。
5. 吐槽不加引号、不加「心里想着」；一章一到三处，一处一种手法（反问、定论、俗语改字、自嘲，选一种）；对准外面的东西（这种日子、画展、明天吃什么）；顺序：触发 → 吐槽句单独成段 → 一句反应 → 零到一句展开 → 一句收回剧情。不造对称俏皮句；「好消息 / 坏消息」不用。
6. 情绪直说：一个短分句点名情绪或判断，再接动作（「她心里痒了一下」「她只觉得闷」）；不用盯着不动、半天没挪开这类定格暗示情绪。
7. 对话一人一段；台词后紧跟一句叙述交代动作或后果（伍宜削苹果、夹菜、坐起、砸东西；晓柒月扣手机、套衣服、摔门）。
8. 往事（她爱挑人、听说伍宜、伍宜离婚）用完整陈述句直说，不写谜语句。

### 场景写作指引

本章涉及 5 种场景类型（daily / fight / dialogue / inner-mono / transition），另始终加载 pov、prose 各 1 条。

- **daily（饭桌）· 先糖后刀：** 伍宜的体贴与刀同场出现——削苹果写得越平常越好，一整条不断的皮是她手巧、耐心的证明，不是凶兆；读者回头才对上。
- **fight（回忆）· 战斗结果导向：** 每一步落在谁占上风、谁泄了；伍宜几次翻盘（③⑥⑦⑨）写出「读者以为晓柒月要输」，⑩一句翻回。
- **dialogue（吵架）· 对话动作穿插 + 连锁反应：** 提分手 → 求 → 崩 → 不哭，一步推一步；台词之间插砸东西、下床、套衣服、笑一声、摔门；晓柒月越轻松，伍宜越崩。
- **inner-mono（走神、最后一个念头）：** 走神只一两句（那一夜 / 现在）；死前念头一句，轻佻、不服、带点好笑，不写成大段独白，不回顾一生。
- **transition（饭桌 → 浴室 → 床 → 她的房间）· 动线镜头：** 每次换地方一句带过（「她在浴室冲澡，……」「她摔门回了自己房间，……」），不写走了多久。
- **pov · 视角分界：** 全章只跟晓柒月，包括回忆；伍宜的内心一处都不进。
- **prose · 三维编织：** 一句里把「发生了什么—她感到什么—她怎么做」织在一起（手机在桌下亮了一下 + 她心里痒了一下 + 扣回去），不拆成三句三段。

### 质感要求

无用细节（须属于当前场景与晓柒月的视角，不按配额插入）：
  1. 饭桌：饭菜的香、苹果皮落在盘子里的样子、伍宜围裙上的什么小东西，可有一两处。
  2. 浴室：水汽、瓷砖的凉，可有可无。
  3. 她的房间：箱子里压皱的衣服、拉链卡了一下这类小事，可有可无（被捅前的平常感）。

对话节奏：允许半截话、语气词、停顿（伍宜「我为了你，家都不要了……」说不完；晓柒月「随便」「都行」只给两个字）。

段落精度分层（按权重分配笔墨）：
  - 高权重（回忆那一夜、吵架、被捅）：细节饱满；回忆段至少三处受力形变 / 反应落到具体部位用在胜负上。
  - 中权重（饭桌、回忆前情与出口）：正常叙事，一句一段往前走。
  - 低权重（浴室、换地方）：写到够看出她走神就收；换地方一句带过。

额外约束（本章特有）：
  1. 回忆段与非性斗段之间不加分隔线，靠「照片」一句切进、「苹果」一句切出。
  2. 各场景之间可空一行，不加分隔符号。
  3. 章末「眼前一黑」之后不再写任何东西。
