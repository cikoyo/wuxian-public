### 1. 规则：系统提示不替主角说出她心里知道的事 [writer-preference]

- **阶段:** 章纲
- **类型:** 规则
- **领域:** 系统提示措辞
- **原文:** 系统提示不说「性斗天赋一次，非性斗天赋一次」，主角心里知道就行；两行抽取提示改为【系统正在为您抽取……】，天赋名行去掉「性斗」二字。
- **结论:** 章纲写系统提示时保持简短，不在提示里加分类说明；主角已知的规则（如一性斗一非性斗）放在她的叙述里带一句即可。
- **场景:** 章纲中照录/编写系统提示的段落
