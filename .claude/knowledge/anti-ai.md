# 活人感写作方法（正向）

> **职责声明：** 本文件是 anti-ai 的正向方法论——先讲"写成什么样"，写完后的清创以 common-rules.md 分级禁用表为准。本文件不定义阈值与档位；句式识别口径（含翻案腔变形外衣）见 common-rules.md T1 节。
>
> 移植自 human-writing skill（MIT License, Copyright (c) 2026 Human Writing Skill contributors），按网文流水线转译。

## 活人感从哪来

活人感不是口头禅、粗口、错别字和网络梗，也不靠烟头、深夜、突然响起的电话这类道具堆出来的"真实感"。它分三层，重要性从高到低：

1. **人物有眼下要办的事。** 要回一笔钱、躲过一次见面、保住体面、让家人相信一句话，都能推动故事，不必每场都是生死选择。
2. **细节跟着人物的视角走。** 紧张的人先看出口，等钱的人盯着手机亮不亮，心虚的人记着对方沉默了多久。
3. **最后才是句式与节奏。**

前两层立住了，第三层的技巧才有处安放；前两层空着，句子层面的规避只是换一种姿势。

## 禁的是修辞动作，不是字面

把一个禁用句式换一套字继续做同一个动作，仍然算命中（变形外衣识别见 common-rules.md T1 节）。拆的办法只有一种：找到这句话原本想下的判断，从正面说出来，依据放在旁边。

## 人物与场景

- **先给人物一件眼下要办的事：** 谁先受到影响、他此刻想得到什么、为什么今天必须行动、什么让原办法失效、这次行动留下什么后果。
- **性格藏在选择里。** 不贴善良/聪明/冷漠的标签，写他在谁面前退让、碰到什么会撒谎、总在哪一步犯同一个错。
- **配角也有眼下要办的事。** 只递消息、制造误会、夸主角的配角，很快露出工具感。
- **每场戏结束时至少改变一项：** 信息、关系、计划、风险、权力、理解、情绪。只换景色和说法、没有人换办法的戏，删短。
- **转折来自人物此前的行动与已存在的规则。** 车祸、绝症、双胞胎、遗嘱、临时新规则不能反复救场。

## 对白在做事

人物说话通常在试探、遮掩、说服、拖延、靠近、推开或保住面子。可以答非所问，可以说一半。两人都知道的背景不为读者重念一遍，角色不轮流替作者讲主题。不同声音来自身份、关系与眼下压力，不靠固定口癖。

## 设定等人物碰到再讲

先问一条规则会改变谁的行动、谁因此得利、谁要付代价。人物没碰到它，正文不提前介绍。规则可以被人物误解，作者不能在需要救场时临时改掉。陌生名词先让读者看见它怎么被使用，再补名字与来历。

## 场景与概述交替

关键选择、关系变化、秘密暴露、无法撤回的动作，用场景慢下来；重复劳动、长途移动、数月流逝，概述过去。全是场景时间走不动，全是概述读者碰不到人物。

## 闲笔与错位必须有来路

闲笔、岔话、情绪错位、信息密度极低的段落都是允许的，但每一处都要从当前场景、人物视角或人物关系里长出来。检验标准：删掉它，这一场的某个信息、气氛或关系会受损；毫不受损的就是插上去的装饰。

明令禁止的表演动作：

- 不按固定间隔插闲笔——"每章第 N 段来一段生活细节"是新的模板
- 不给每章配一处错位反应凑数——错位出自人物性格或场景压力，该错位时才错位
- 连续短句是鼓点；单句成段只留给确实需要停一下的地方
- 不穿论坛服装——口头禅、粗口、网络梗只有这个人物真会这样说时才留

# 反AI通用规则 — 三级分级禁用表

> **职责声明：** 本文件是反 AI 规则的**唯一权威**——所有数量阈值、禁用词档位、句式规则以本文为准。其他文件（anti-ai-writing、chapter-quality-checklist）不得重复定义阈值，只能引用。
>
> 所有题材共用。anti-ai 逐项清除阶段的核心参考。

## 三档处理逻辑

| 档位 | 处理方式 | 对应原词 |
|------|---------|---------|
| **T1 出现即换** | 出现即标记、替换，0 容忍 | ★★★★★ 最毒句式 + 一级禁用词 |
| **T2 同段聚集** | 同一段落内出现 2+ 次才标记，只保留最贴切的一个；单次出现不处理 | 现有二级词的聚集版 |
| **T3 全文密度** | 全文密度过高才处理，不设逐词阈值，以段落/字数比例为准 | 基础词、结构骨架词 |

判定优先级：T1 > T2 > T3。同一词出现在多个档位时按最高档处理。

---

## 一、T1 出现即换（原 ★★★★★ + 一级禁用词）

出现即替换，0容忍。

### 最毒句式（★★★★★）

| 句式 | 示例 | 处理 |
|------|------|------|
| "不是A，（而）是B" | "他不是生气，而是失望" | 直接写 B |
| "带着……" 万能状语 | "他看着窗外，带着一丝惆怅" | 拆短句或换动作 |
| "仿佛/犹如/宛若……一般" | "声音仿佛从很远的地方传来" | 删除或白描 |
| "让/令/使" 句式 | "这一幕让他想起了童年" | 删"让"，主语直接行动 |
| "当……时/的时候" | "当他推开门的时候" | 拆成独立动作句 |
| 认知动词前置 | "他意识到/他感到/他注意到" | 删掉，直接写事实 |
| "与此同时" | "与此同时，在另一个地方" | 直接换场景开头 |

#### 变形识别：禁的是修辞动作，不是字面

把"不是A而是B"换一套字继续做同一个动作，仍按 T1 处理。常见外衣：

| 外衣 | 例子 |
|------|------|
| 字面翻案 | 不是A，而是B。并非A，而是B。不在于A，而在于B |
| 省字变形 | 不是A，是B。不是A，B才是 |
| 跨句变形 | 不是A。而是B。表面上是A。其实是B |
| 换字变形 | 与其说A，倒不如讲B。与其说A，毋宁说B |
| 以为体 | 你以为A，其实B。我一直以为A，后来才发现B。回头才发现 |
| 让转体 | 看似A，实则B。大家都说A，可真相是B。答案恰恰相反 |
| 抬价体 | A不重要，重要的是B。真正值钱的从来都与A无关 |

拆法只有一种：找到这句话原本想下的判断，从正面说出来，依据放在旁边。正文确实用情节走过了"从误解到修正"的过程时，可保留一次自我修正，但不能穿上述任何一件外衣。

---

### 一级禁用词（出现即替换）

### 情态类

| 词 | 替换策略 |
|----|---------|
| 仿佛、犹如、宛若、如同 | 删除或白描 |
| 一丝、一抹、些许、几分 | 具体量词或删除 |
| 不禁、不由得、不由自主 | 直接写动作，保留有节奏功能的 |
| 突然、忽然、猛然 | 已移至语境敏感类（≤4次/章），红线段落从宽 |

> **注意：** 上述规则的目的是降低AI腔调的均匀度，不是完全禁止正常表达。适度使用（≤2次/段，≤3次/章）不构成AI味——当某个词在段落中有节奏功能时可保留。

### 动作类

| 词 | 替换策略 |
|----|---------|
| 瞳孔一缩、身体一僵 | 用具体身体反应替代 |
| 倒吸一口凉气、呼吸一滞 | 用呼吸变化细节替代 |
| 露出（表情） | 用具体笑法/表情动作替代 |
| 陷入（沉默） | 写沉默后的具体行为 |
| 涌起、泛起（情绪） | 用身体反应替代 |

### 表情类

| 词 | 替换策略 |
|----|---------|
| 嘴角勾起一抹…… | 用具体动作（他笑了一下/嘴角动了一下） |
| 眼中闪过一丝…… | 用动作替代（他低下头/他把目光移开） |
| 脸上露出…… | 用具体的五官变化替代 |

### 心理类

| 词 | 替换策略 |
|----|---------|
| 感到、觉得、意识到（引导心理） | 优先用动作替代，关键心理节点允许≤2次/章 |
| 心中涌起一股…… | 用动作替代 |
| 他的内心…… | 用行为展示 |
| 他这才意识到/明白 | 建议改为具体反应，但红线段落可保留 |
| 他不禁/不由得 | 优先直接写动作，保留有节奏功能的 |

### 判断类

| 词 | 替换策略 |
|----|---------|
| 显然、显而易见 | 谁都知道 / 直接陈述事实 |
| 毫无疑问 | 肯定 / 直接陈述 |
| 不容置疑 | 就是 / 直接陈述 |
| 似乎、也许、大概、或许（高频） | 删除或换具体状态 |
| 竟然、居然（高频） | 让读者自己判断 |

### 形容类

| 词 | 替换策略 |
|----|---------|
| 坚定的、深邃的、冰冷的（万能形容词） | 删掉或换具体状态 |
| 温暖的、柔和的（泛光感） | 用具体光影描述 |
| 所谓 AABB 式形容词 | 仅保留生活化用法 |
| 缓缓地、慢慢地（修饰动词） | 删掉，或换具体速度 |
| 某种、一股、一阵（搭配抽象情绪） | 删掉或具体化 |

### 过渡类

| 词 | 替换策略 |
|----|---------|
| 然而、不过 | 已移至 T2 — 同段出现≥2次才标记，单次出现保留 |
| 于是 | 已移至 T3 — 全文≤3次/章，保留叙事功能明显的 |
| 与此同时 | 直接换场景开头 |
| 总之、综上所述、总而言之 | 删掉 |
| 本章、下一章、故事还在继续 | 删掉（元叙事禁止） |

## 二、T2 同段聚集 + T3 全文密度

### T2 同段聚集（标记条件：同段 ≥2 次）

同一段落中出现 ≥2 次才标记，只保留最贴切的一个。单次出现不处理。

| 词 | 替换策略 |
|----|---------|
| 然而、不过 | 同段出现 ≥2 次 → 保留一个，其余删除 |
| 此外、另外、同时 | 同段出现 ≥2 次 → 合并或拆分 |
| 虽然…但是…、尽管…却… | 同段出现 ≥2 组 → 只保留一组 |
| "了"字聚集（同段 ≥4 个） | 标记该段供作者判断，标记后不自作主张修改 |

### T3 全文密度（标记条件：全文范围比例超标）

不设逐词阈值，以全文段落/字数比例为准。比例超标才标记。

| 检测项 | 超标线 | 处理 |
|--------|-------|------|
| "了"字密度 | 平均每段 >2.5 个 | 标记超高密度段落，保留关键"了" |
| 句号密度 | 连续 10 句以上句号结尾 | 部分句号改逗号/省略号打碎 |
| 段长均匀度 | 连续 5 段句子数差值 ≤1 | 打散或合并制造长短变化 |
| 基础词密度 | 重要/关键/核心 >3 次/章 | 替换为具体描述或删除 |

### 语境敏感类（跨档位，按语境判断）

超阈值时触发替换，未超限可保留。**已出现在 T2/T3 的词优先按 T2/T3 处理。**

| 词 | 阈值 | 替换策略 |
|----|------|---------|
| 突然/忽然/猛然 | ≤4次/章 | 红线段落从宽，保留节奏功能的 |
| 竟然/居然 | ≤3次/章 | 降低处罚，允许适度保留 |
| 渐渐/逐渐 | ≤2次/章 | 用变化细节替代 |
| 依旧/仍然 | ≤2次/章 | 用状态描写替代 |
| 似乎/也许/大概/或许 | ≤3次/500字 | 适度放宽，保留必要的模糊判断 |
| 于是 | ≤3次/章 | 保留叙事功能明显的 |

### 书面腔

| 词 | 替换策略 |
|----|---------|
| 瓦解 | 消失/散了/没了 |
| 毋庸置疑 | 肯定/就是 |
| 显而易见 | 谁都知道 |
| 内心深处 | 删掉或直接写动作 |
| 此时的他还不知道 | 删掉（上帝视角禁止） |

### 总结句式

| 句式 | 处理 |
|------|------|
| "这就是……" | 删除，让场景自然结束 |
| "他终于明白了……" | 删除，停在画面/动作上 |
| "一切……都……" | 删掉或改为具体状态 |
| "他不知道的是……" | 删除或换具体钩子 |

### 排比句式

| 模式 | 处理 |
|------|------|
| "也许是……也许是……也许是……" | 保留最强一条，其余打散 |
| "不是……不是……而是……" | 直接写"而是"部分 |
| "既没有……也没有……更没有……" | 只保留最具体一条 |
| "既X又Y" 对称填充（"既紧张又兴奋"） | 删一边，留主要的一侧 |
| "不仅仅……更是……" 价值拔高骨架 | 删"不仅仅是"部分，留"更是"后的事实 |
| "首先…其次…最后" 机械排列 | 打散为自然叙述，不要列举感 |
| "从X到Y，从A到B" 排比遍历 | 选一到两个最具代表性的，其余删掉 |
| "没有……没有……甚至没有……" 否定排比 | 只保留最具体一个，或打散为陈述 |

### 升华句式

| 模式 | 处理 |
|------|------|
| "这一夜注定……" | 删除 |
| "从这一刻起……" | 删除 |
| "也许这就是……的意义" | 删除 |
| "未来可期/拭目以待/来日方长" 正能量收尾 | 删除，停在具体画面上 |
| 感叹号收尾（"……！"） | 改为句号或动作 |

## 三、禁用句式模板

### 比喻类

| 类型 | 处理 | 例外 |
|------|------|------|
| AI 模板比喻（"像一幅画卷"） | 删除 | — |
| 通用比喻（"像……一样"） | 删除或白描 | — |
| 生活化比喻（"像被蚊子咬"） | 保留 | 符合角色认知 |
| 角色化比喻（"像他爸揍他那样"） | 保留 | 贴合角色背景 |
| "仿佛/犹如/宛若" 引导 | 删除 | — |

### 结构类

| 句式 | 处理 |
|------|------|
| "连续4句相同主语" | 变换主语和句式 |
| "连续3段相同开头" | 每段首句主语/场景不能重复 |
| "连续5句相同句式" | 陈述/短句/对话交替 |
| "连续2段描写同一物" | 景物/人物不重复描写 |
| "相同比喻复用" | 用过的比喻/意象本章不再用 |
| "同一情绪词重复" | 紧张/开心/难过等情绪词单章≤3次 |

### 标点类

| 规则 | 说明 |
|------|------|
| 破折号（——） | 用法判定，不计数。允许停顿/节奏、对话被打断；删除间注式冗余。详见下方破折号判定 |
| 对话中声音中断用"…"或直接断句 | 沉默用句号收尾 |
| "了"字净化（警告） | 连续3句5个以上"了" → 标记段落供作者判断，不自作主张修改 |

#### 破折号判定（正反例，不靠数量线）

> 判定原则：删掉破折号及其两侧内容，意思是否变模糊？不变则删。

✅ **保留·停顿/节奏**（破折号后接的是动机/因果/状态补足，删掉后意思变模糊）
「磨石声沙沙，磨两下，停一下——他怕磨偏。」
「藤条勒得爪心发紧——他握了握，不松。」

✅ **保留·对话被打断**（话音没说完被外力掐断）
「你——」话音被撞进来的声音打断。

❌ **删除·间注式冗余**（破折号包裹的是可独立成句的同位语/解释）
「他——一个在铁匠铺干了二十年的老师傅——拿起锤子。」
→ 改：「他拿起锤子。」（"铁匠铺二十年"挪到别处交代）

⚠️ **诊断信号·同段密集**（一段内出现三处及以上破折号，通常是间注冗余的聚集）
→ 不是硬删除，逐处按上方用法判定核对：真正保留的通常只有一处，其余改句号或拆段。

### 反问与假设骨架

| 句式 | 处理 |
|------|------|
| "如果我告诉你……" 反问式铺垫 | 直接陈述结论，不需要先反问再回答 |
| "你有没有想过……" 引导式反问 | 删掉引导，直接写事实 |
| "想象一下……" 假设导入 | 删掉，直接描写 |
| "研究表明……" 无源引用 | 删掉"研究表明"或换为具体来源 |

## 一、AI 写作指纹

AI 生成的文本在统计层面有稳定的特征模式，以下是指纹识别依据。

### 1.1 高频词指纹

AI 偏好使用特定高频词，这些词在人类写作中分布稀疏：

| 类别 | 典型词 |
|------|--------|
| 情态副词 | 突然、仿佛、不禁、依然、逐渐 |
| 判断弱化 | 似乎、也许、大概、有些、某种 |
| 书面连接 | 然而、与此同时、由此可见、综上所述 |
| 万能动词 | 露出、陷入、涌起、泛起、闪过 |
| 心理引导 | 感到、觉得、意识到、明白 |
| 书面填充 | 为了实现这一目标、由于……的事实、在这个时间点 |

### 1.2 章末总结体

AI 在章节结尾处有强烈的总结和升华倾向：

- "他不知道自己即将面对……"
- "从这一刻起，一切都将不同"
- "这一夜，注定……"
- "也许，这就是成长的意义"

### 1.3 叠加式描写

AI 倾向用多层修饰叠加来制造"文学感"：

- 多层定语："他眼中闪过一丝复杂难言的、连他自己也说不清楚的情绪"
- 情绪+动作+环境三件套："他深吸一口气，望着远方的天际线，心中五味杂陈"
- 副词堆叠："他似乎隐隐约约地感觉到……"

### 1.4 均匀分布

AI 在微观层面有稳定的均匀分布倾向：

- **句长均匀**：长短句波动幅度小，很少出现 2-3 字超短句
- **段落均匀**：段落长度分布集中，缺少极短短段（1-2 句）和极长段（10+ 句）
- **词频均匀**：各词汇出现频率分布平坦，缺少核心词的合理重复
- **标点均匀**：句号和逗号比例稳定，缺少破折号、顿号等非常规标点
- **同义词循环**：受"不要重复"驱使，AI 每段换说法指称同一事物（"主人公/主要角色/中心人物"轮换）；真人有个人高频词，核心名词、术语反复使用同一说法
- **主语补全均匀**：AI 几乎每句都补全主语；真人中文大量省略主语，口语叙述尤甚

## 二、核心规则

### 规则 1：段落密度

| 原则 | 说明 |
|------|------|
| 单段只讲一件事 | 动作、环境、对话、情绪，不塞进同一段 |
| 信息密度递减 | 关键信息在前，补充信息在后 |
| 短段优先 | 能用 2 句说完不用 5 句 |

理想段落长度分布（以句数为单位，定性指引非硬性指标）：

| 段落类型 | 建议比例 | 作用 |
|---------|---------|------|
| 独句段 | 建议 10%-30% | 节奏变化、强调（不要整章通篇独句段） |
| 2-5 句段 | 主体叙事 | 常规段落，信息密度适中 |
| 6+ 句段 | 按需使用 | 复杂场景允许，注意信息密度不要过于均匀 |

### 规则 2：动作 + 对话 + 情绪

情绪描写的优先级：

1. **动作**（最好）："他把杯子往桌上一顿"
2. **对话**（次好）："你什么意思"
3. **身体反应**（再次）："他的手在抖"
4. **直述**（最差，仅在关键情绪节点允许1-2句简短直述）："他很愤怒"

### 规则 3：长短句结合

- 长短句自然交替，避免通篇长句或通篇短句
- 关键信息可用短句突出，氛围描写可用长句铺陈
- 长句（>40 字）之间建议有短句隔开调节节奏

### 规则 4：口语化

- 对话要短、要碎、要有留白
- 叙述语言偏向口语节奏，不是书面作文
- 允许"然后""反正""其实"这类日常口语词，但低频

## 三、Show Don't Tell 原则

### 3.1 核心公式

```
Tell: 情绪词/判断句 → 读者被告知
Show: 身体反应/动作/环境/对话 → 读者自己感受
```

### 3.2 对照表

| Tell（禁止） | Show（推荐） |
|-------------|-------------|
| 他很紧张 | 他手指在桌沿敲了三下，又三下 |
| 她很生气 | 她把手机屏幕朝下扣在桌上 |
| 这是个破旧的小镇 | 墙皮剥落的地方露出红砖，巷子里晒着被单 |
| 他感到不安 | 他走两步就回头看一眼 |
| 她很开心 | 她脚尖在地上点了两下 |
| 气氛很尴尬 | 他低头喝水，喝完发现她还在看他 |
| 他心里很乱 | 他把烟点起来，吸了一口又掐灭 |

### 3.3 五感检查

每段场景描写问自己：

- [ ] 视觉——他看到了什么？（不是"美丽"，是"墙上有裂缝"）
- [ ] 听觉——他听到了什么？（不是"安静"，是"只有钟在走"）
- [ ] 触觉——他感觉到了什么？（不是"冷"，是"门把手冰了一下"）
- [ ] 嗅觉——他闻到了什么？（不是"香味"，是"药汤苦得他皱了整张脸"）
- [ ] 动觉——他的身体在做什么？（不是"站着"，是"他换了个脚撑着重心"）

## 四、AI 写作模式检测

### 模式 1：总结式开头/结尾

```
信号：段首/段尾出现总结性判断
特征："这就是""这意味着""他明白了""总的来说"
修复：删掉总结，停在具体画面/动作上
```

### 模式 2：内心分析报告

```
信号：大段规整心理描写（>3 句连续心理）
特征："他内心深处知道……""一方面……另一方面……"
修复：打碎为 1-2 句，余下的用动作外化
```

### 模式 3：完美逻辑链

```
信号：每句话都是上一句的直接因果结果
特征：没有闲笔、没有走神、没有无关细节
修复：在两句因果之间插入一句无关观察
```

### 模式 4：均匀信息密度

```
信号：每段都在推情节，没有疏密变化
特征：从头到尾信息浓度一致，没有喘息段
修复：选一段插入生活化细节（走神/看窗外/想起无关的事）
```

### 模式 5：模板情绪反应

```
信号：情绪反应是"最合理的选择"
特征：该哭时哭、该怒时怒、该紧张时紧张，全程无可挑剔
修复：改一处为错位反应——该哭时笑、该怒时发呆、该紧张时跑题
```

### 模式 6：全线平滑

```
信号：所有段落转换都顺畅自然
特征：没有突兀跳跃，每段开头都有平滑承接
修复：如果整章所有段落转换都平滑无变化，考虑删掉1-2段过渡句制造节奏变化。
注意：不要为硬切而硬切——自然的过渡是必要的。
```

### 模式 7：标点规整

```
信号：句号和逗号比例稳定，缺少非常规标点
特征：几乎不用破折号、顿号、省略号；句幅变化小
修复：加 1-2 处用顿号/省略号的碎句，制造标点不规则感
```

### 模式 8：对称填充

```
信号：句子结构对称工整，前后分量均衡
特征："既X又Y""不仅X更Y""从A到B"
修复：打破对称，只保留强的一侧，弱侧直接删掉或改成独立的短句
      不是"既紧张又兴奋"→"他紧张得手心出汗。又有点兴奋。"
      不是"从清晨到日暮"→"天亮了。又黑了。"
```

### 模式 9：机械列举

```
信号：显式的顺序或平行结构，读起来像提纲
特征："首先…其次…最后""第一…第二…第三""一方面…另一方面…"
修复：打碎为自然叙述，用时间/因果/感受承接代替序号词
```

### 模式 10：反问与假设引导

```
信号：先抛一个反问/假设再回答，制造不必要的悬念感
特征："如果我告诉你……""你有没有想过……""想象一下……"
修复：删掉引导句，直接陈述。读者不需要先被问再被告知。
```

### 模式 11：正能量收尾

```
信号：章末出现鸡汤/励志/希望感总结
特征："未来可期""拭目以待""来日方长"（含变体）
修复：删除，停在具体的画面/动作上。情绪留给读者自己消化。
```

### 模式 12：无源引用

```
信号：提到研究/数据/证据但不给出处
特征："研究表明""据统计""调查显示"
修复：删掉"研究表明"或补具体来源。小说中绝大部分可以直接删掉。
```

### 模式 13：系动词回避

```
信号：用复杂结构替代"是/有"的简单判断
特征："作为……是……""拥有……提供……"——AI 回避系动词制造书面感
修复：还原为直接判断（"作为急诊医生的他很清楚"→"他当过急诊医生，很清楚"）
```

### 模式 14：过度限定堆叠

```
信号：一句话里"可能""也许""或许"连用堆叠不确定性
特征：判断本身模糊，再用多枚模糊词加保险
修复：保留一枚（或全删），把判断落到具体观察上
```

## 五、系统性去 AI 三遍法

### Pass 1：去泛化（~80% 的 AI 味集中在此）

**目标**：替换抽象/套话表达为具体细节。

步骤：
1. 全文扫描禁用词（★★★★★ 最毒句式 → 一级禁用词）
2. 替换情态词（仿佛/一丝/不禁 → 删除或白描）
3. 替换情绪词（愤怒/难过 → 身体反应）
4. 替换模板描写（眼中闪过一丝 → 动作）
5. 替换句式（不是A而是B → 直接写B）

验证：禁用词命中率下降 80% 以上。

### Pass 2：去书面化

**目标**：书面腔/翻译腔 → 口语和动作。

步骤：
1. 扫全知叙述（他不知道…… → 删除）
2. 扫心理分析（他内心深处 → 动作外化）
3. 去内心辩论赛（一个声音说…… → 保留结论）
4. 简化对话标签（他愤怒地说 → 动作承接）
5. 去副词修饰（他缓缓地 → 删掉）

验证：对话标签密度 <10%，无全知叙述。

### Pass 3：回自然感

**目标**：让文本有人写的痕迹——自然的停顿和节奏变化。

步骤：
1. 检查节奏是否过于均匀——如有，制造自然的起伏（长短交替、信息密度变化）
2. 视情况补闲笔（仅当通篇信息密度均匀时：在属于当前场景与人物的位置补生活化细节，不服务于主线）
3. 视情况补错位（仅当情绪反应全程都"最合理"时：在人物性格或场景压力托得住的位置改一处）
4. 修结尾（升华/总结/预告 → 画面/动作）

验证：段落长度有自然变化；闲笔与错位（若有）出自当前场景与人物，非按配额插入。避免刻意碎句。

### 场景分级改写力度（段落类型 × 改写幅度）

不同段落类型改写力度不同——误杀防护（见 boundary-cases.md）决定"哪里不能碰"，本表决定"碰多深"：

| 段落类型 | 识别信号 | 改写力度 | 保护项 |
|---------|---------|---------|--------|
| 叙事段 | 动作描写、场景推进 | 重改（可大段重写） | 情节走向、关键动作 |
| 对话段 | 引号、对话标签、问答 | 轻改（只改标签和节奏） | 台词原文、数字、归属 |
| 内心段 | 判断、联想、回忆 | 中改（改句式，保内容） | 判断方向不反转 |
| 回忆段 | 过去时态、具体日期、往事 | 轻改（保事实骨架） | 时间线、人名、事件细节 |
| 引用外部文字段 | 书信、屏幕原文、消息原文 | 不改 | 逐字保留 |

## 六、改写范例库

### 6.1 情绪外化

**愤怒：**

❌ "他心中涌起一股无法遏制的怒火"

✅ "他把杯子往桌上一顿。水溅出来，顺着桌沿往下淌。他没擦。"

**紧张：**

❌ "他紧张得手心冒汗"

✅ "他在裤腿上蹭了一下手。又蹭了一下。桌沿被他摸得发亮。"

**悲伤：**

❌ "她感到一阵难以言说的悲伤"

✅ "她把外套叠了三叠，放回衣柜最里面。拉链没拉到头。她又拉开了，重新拉好。"

**惊讶：**

❌ "他震惊得说不出话来"

✅ "他张了张嘴。没出声。又张了一下，还是没出声。"

### 6.2 场景描写

**环境：**

❌ "夕阳西下，天边的云彩被染成了金红色，美得令人窒息"

✅ "六点一刻，太阳还没落完。影子拉得很长，他的影子比他自己高两个头。云不红，是灰的，像没洗干净的抹布。"

**天气：**

❌ "雨下得很大，仿佛天空破了一个洞"

✅ "雨打在铁皮棚上，声音大得听不见人说话。他的裤脚湿透了，鞋里也进了水。"

**建筑：**

❌ "城堡巍峨耸立，塔尖直入云霄"

✅ "城堡墙上有裂缝。他路过的时候数了数，有七条。最长的那条能伸进去两根手指。"

### 6.3 打斗

❌ "他身形一闪，躲过对方的攻击，随即一个回旋踢正中对手胸口"

✅ "对方一拳过来。他偏头，慢了半拍，拳风擦过耳朵，耳朵嗡了一声。他没回旋踢——他没那么利索——他往前一撞，脑门磕在对方鼻梁上。"

### 6.4 结尾

**错误示范：**

❌ "他望着远方的天际线，心中充满了对未来的期待。他不知道的是，更大的挑战正在前方等着他。这一夜，注定不平凡。"

✅ "他把烟掐灭。鞋底碾了一下。转身往回走。"

**错误示范：**

❌ "从这一刻起，他终于明白，真正的勇气不是无所畏惧，而是心怀恐惧却依然前行"

✅ "他站起来。膝盖上沾了两片草叶。他拍了一下，没拍掉。算了。"

### 6.5 节奏对比

**AI 均匀节奏：**

"他走进房间，环顾四周，房间里很安静，只有钟在走。他拉开窗帘，阳光照进来，灰尘在光柱里飘。他在床边坐下，床垫弹了一下。"

**真人碎节奏：**

"他推开门。钟在走。没别的声音。
窗帘拉开的瞬间，灰在光柱里翻了一下，又沉下去了。
他往床上一坐。弹了两下。"

### 6.6 身体反应替换

**瞳孔一缩：**

❌ "他的瞳孔微微一缩"

✅ "他看了三秒。低头翻了一页文件。又翻回来看了一遍。"

**倒吸一口凉气：**

❌ "他倒吸一口凉气"

✅ "他往后靠了靠。椅背硌得后背疼。他又往前坐了回来。"

**身体一僵：**

❌ "他身体一僵"

✅ "他脚钉在原地没动。旁边有人绕开他走过去，他也没注意到。"

**心中涌起：**

❌ "他心中涌起一股暖意"

✅ "他把那杯茶捧在手心里。没喝。茶凉了也没放下。"

**露出/脸上露出：**

❌ "他脸上露出一个微笑"

✅ "他笑了一下。笑到一半，发现没人接，又把笑收了回去。"

# 误杀防护 — 不改清单

> anti-ai 管线执行时，以下场景**跳过检测**。防止去 AI 味过度导致角色同质化。

## 一、角色化表达不改

### 口头禅 / 口癖

- 角色固定的口头禅、语气词、停顿习惯不改
- 例：角色A说话爱带"就是说"，角色B爱带"你懂吧"，角色C紧张时会结巴
- 无论是否命中禁用词表，**角色口头禅不触发 Gate A/B/C**

### 性格化语法错误

- 角色因文化水平/性格导致的语法错误不改
- 例：文盲角色说"俺不知道"，大大咧咧角色说"不是我说你啊"
- 判定标准：错误是否贴合角色设定中的层6（出身）+ 层2（自我定位）

### 特定叙事腔调

- 第一人称吐槽风格不改（心理活动有大量口语/偏激/不准确表达）
- 角色在情绪极端时的反常表达不改（怒极反笑、悲极沉默、焦虑时话多）
- 叙述者年龄/气质带来的特殊句式不改（儿童视角/老人回忆/老兵口述）

## 二、对话特例不改

### 完整句式豁免

- 对话中出现的书面语/完整句式，属于角色性格故意为之的不改
- 例：学者角色在对话中也用完整句式——这不是 AI 味，是角色设定
- 判定标准：对照角色设定层5（技能）和基本信息·语言特征

### 对话情绪词豁免

- 对话中直接出现情绪词不改——人在对话中会说"我很生气""我很难过"
- 改为标记"对话内情绪词"，仅用于量化统计，**不触发替换**

### 对话标签豁免

- "他说""她问"等基本对话标签不改，因为这是叙事基础设施
- 只处理**过度修饰**的标签（"他愤怒地说""她轻声说道"中的副词部分）

## 三、特定的叙事功能不改

### 标点功能豁免

| 场景 | 示例 | 处理 |
|------|------|------|
| 对话被打断 | "你——"他的话没说完就被打断了 | 保留破折号 |
| 角色声音拉长 | "等——一——下——" | 保留 |
| 内心活动的省略 | "她记得……不，也许记错了" | 保留省略号 |
| 顿号列举 | "桌上摆着笔、纸、手机、钥匙" | 保留（生活化列举） |
| 顿号列举（AI 模板） | "这里象征着勇气、坚韧、希望、未来" | 标记（抽象概念列举） |

### "了"字功能豁免

| 场景 | 不改 | 改 |
|------|------|----|
| 对话完成态 | "我知道了""好了""走了啊" | 不改（口语完成态） |
| 动作完成 | "他站了起来" | 可改 → "他站起来" |
| 连续完成时态 | "他站了起来，走了出去，关上了门" | 保留一个"了" |
| 状态变化 | "他开始懂了" | 不改（习惯用法） |

### 排比句式功能豁免

| 场景 | 不改 | 改 |
|------|------|----|
| 角色刻意排比 | 角色有演讲/辩论/煽情需求 | 保留，不触发自动替换 |
| 意识流 | 角色在情绪高点使用排比增强语气 | 保留，仅标记 |
| AI 模板排比 | "也许是……也许是……也许是……" | 改 |
| 机械列举 | "首先…其次…最后" | 改 |

## 四、Gate G·风格偏差豁免

| 类别 | 说明 |
|------|------|
| 场景类型刻意偏离 | 战斗场景刻意用短句、对话场景刻意长对话/低对话占比——若与场景卡标注的该场景 override 一致，不算偏差 |
| 人物口癖 | 角色化重复用词/句式（已在前组豁免） |
| 不确定 | 判定结果不确定（疑似误杀，无现档位可套——现为 T1/T2/T3 档位 + 轻/中/重定级 + Gate G PASS/FAIL）→ 标 `[疑: 疑似误杀]` 不改，报作者确认 |

## 五、写作实操指引

### anti-ai agent 执行规则

```
检查命中 → 是否在 boundary-cases 列表中？ → 是 → 跳过（标注 SKIP）
                                           → 否 → 按 common-rules 处理
```

- 每次 Phase 3 执行前，先读 boundary-cases.md
- 每个 Gate 命中先做"是否豁免"判断，再决定改不改
- 标记为 SKIP 的命中统计入量化指标**但不修改**

### 不确定时

- 有歧义的命中 → 保留原文，在 Phase 4 报告中标注 `[疑: 疑似误杀]`
- 需要作者判断的 → 打在报告中，不做修改

# 结构热源定律 — 从源头规避 AI 检测的结构知识

> **适用范围与证据来源：** 本文件的经验来自现实题材单书的外部 AI 检测实测攻防（连续多章达成检测器全部片段"人工特征"判定，单章最长 44 轮迭代）。定律与数字是**默认值**，按文风与题材校准；证据分数为该单书实测值，用于说明方向，不是通用常数。
>
> **冲突裁决顺序：** 作者设定与章纲 > 题材知识 > 本文件结构默认值 > 检测优化。与作者侧冲突时，作者侧优先，检测优化不得覆盖锁定台词、章纲落点等作者核心表达。
>
> **与 common-rules.md 的分工：** common-rules 管词句级（禁用词、句式、标点），本文件管段落/场景/位置级结构。同一现象不重复定义数值口径；词句命中见 common-rules，结构命中见本文件。

---

## 一、七条实测定律

### 定律 1：问答链密度定律

**对话不是人味信号，一问一答的乒乓链才是 AI 信号。** 单窗口 300 字内问答超过约 8 拍即高风险（实测：8-13 拍窗口 0.68-0.74，动作叙述窗口 0.22-0.49）。

修法唯一：砍拍数、裸台词改动作前置归属、问答之间插动作拍。给窗口加拍必反升。

### 定律 2：对话密度定律（正向）

**对话占比高是冷信号，纯叙述密度是 AI 信号。** 实测：约 85% 对话密度的章节逐片 0.09-0.11；纯叙述段反复改词仍在 0.63-0.86。

修法：把叙述压到只剩事实句，信息拆进对话。转述连排（"他问我怎么样。我说没问。"）在孤立窗口内同样热，改成两行带归属的对话立即降。

### 定律 3：位置热值定律

检测按比例切片，**章首约 9-17% 与章尾约 10% 的切片对措辞手术免疫**——分数由"位置 × 内容类型"决定，不由用词决定。实测：同一章首位置三种完全不同的内容连续三轮 0.59→0.68→0.69。

- 章首默认冷开场：对话或动作顶第一行，禁"时间标记 + 场景状态"式开头。
- 章尾禁内心排比、三连状态罗列、对称双人反应、静物清单收束；停在动作、物件、完整台词或未解决后果上。

### 定律 4：切片边界稳定定律

检测切片按语义边界走（实测约 250-540 字/片），**任何修改都可能重划边界、让热点横跳**。修窗时：窗口首句末句逐字保持原样，改幅等长优先；其余窗口字符级不动，禁止顺手润色。

### 定律 5：补字铁律

新句、新段、新信息必然加热其所在位置或重划切片。字数缺口唯一安全的补法是**同位置行内拉长**：台词补语气词、叙述加同义复述——行数、段数、句号数不变，切片边界纹丝不动（实测：逐行拉长补足字数后分数不升反降 0.04；同量字数用现成句子回补则重划出 3 个热窗）。

### 定律 6：内容类型切换定律

同一窗口连续两轮改善不足 0.05 或分数反升，**禁止第三轮同类改法**（继续换词、换物件、换动作顺序都是同类）。先写出现有内容类型（争议场、证明场、流程场、悬念场、生活岔话），下一轮必须换类型；换类型仍反升的固定位置块，压缩极简化让切片边界落进已知冷区。

### 定律 7：整章重写边界

压缩、搬运、并场**不算**整章重写（实测均无效）；换内容类型 + 换归属方式 + 重排场景顺序才算。重写前先存快照、列"已修复问题清单"逐条对照——历史修掉的结构（并拍、夹层、转述连排）凭手感写回来是重写失败的主因。

## 二、十三种高风险结构

热源在结构形状，不在用词。以下任一形状出现，先改结构再清句子（对应四里的自查卡）。拆法共同原则：**让人物只办眼前这一步，结果不满分、回执不齐全、证据不排齐。**

| # | 结构 | 热源形状 | 拆法 |
|---|------|---------|------|
| 1 | 工作汇报体 | 派任务→逐项执行→报齐→确认→安排下一步 | 让人物对着界面/现场只发现当前缺口，不写"都完成了" |
| 2 | 取证结案体 | 发现线索→记录→核对→补来源→判断意义→锁定 | 只写当下看见的痕迹，证据不足明确停在"不知道" |
| 3 | 经营验收体 | 报价→核算→分账→规则→合同状态→总结学会 | 让钱卡住一个具体选择，一次只处理一笔钱 |
| 4 | 协作示范体 | 教方法→失败→纠正→熟练→总结默契 | 保留一次误读和当场修正，删"后来配合得很好" |
| 5 | 前置准备体 | 接电话→复盘→备材料→分工→出发→准时抵达 | 直接进主场景，材料在现场需要时才回补 |
| 6 | 数字讲解体 | 这个数什么概念→换算→配角评价→旁白再总结 | 同一数字只结算一次：落到一个动作或决定上 |
| 7 | 微闭环递归体 | 小窗口独立完成"出现→确认→执行→反馈" | 按 300/200/150 字递归扫描，任一窗口四项齐全砍到最多三项 |
| 8 | 连续验收叠加体 | 同场多套回执：签字生效+到账+授权+核查全兑现 | 同场最多一个结果获得明确回执（爽点兑现场的单回执豁免） |
| 9 | 固定位置换皮体 | 章首/章尾同位置连续换内容仍热（位置在收税） | 停止发明第四种小戏，极简化把切片边界推进冷区 |
| 10 | 标准悬念搭台体 | 异常物件→来源→眼熟→回忆→否认→指图→末句提问，所有句子都服务钩子 | 插入不服务钩子、会跑偏的私人岔话打断搭台（默认深度项，钩子强度让位于章纲时才用） |
| 11 | 过桥链前缀体 | 旧信息到场→确认不知→指出谁能知→立即获准（许可即回执，执行未发生已热） | 从新信息节点扫到第一个许可/决定/转场，撤掉一层明确因果，许可在无关岔事后独立出现 |
| 12 | 私人回忆证明链 | 物件触发→连续多个证据→段尾确认"某人其实爱我" | 同一回忆窗口只留一条完整情绪链，其余改记忆误差、争执、被打断；补字数时禁新增温情证明段 |
| 13 | 固定章首完整小戏 | 章首独立承担有起承转合的完整小戏，切出来自成一块 | 章首极简（默认百字上下过门），低分主体字符级锁定 |

---

## 三、修复纪律（检测反馈后）

1. 每轮只修一个最高分窗口，其余窗口字符级不动（哈希验证）。
2. 窗口首末句逐字保持，改幅等长优先；先还原窗口内自己改过的段，再动唯一非锁定段。
3. 同窗口连续两轮改善不足 0.05 或反升 → 按定律 6 换类型或回滚，不做第三轮同类改法。
4. 全部片段低于阈值即锁版（快照 + 哈希），一字不磨。
5. 每轮的轮次、改动、逐片结果记入项目 `sandbox/detect-battles.md`；翻车原句经作者确认后加入 `sandbox/prose-regressions.txt`——这是本文件所有定律的产生机制。

## 四、写前自查卡

**每场五行反闭环卡**（答不出第 3-5 项不开写）：

1. 人物此刻只想办成什么？
2. 阻力从谁的即时反应产生？
3. 本场只演到哪一步就停？
4. 哪些结果不解释，让读者自己看？
5. 哪条信息留到下一场，不在本场验收？

**落盘后结构八问**（任一"是"先改结构，再跑词句检查）：

1. 是否有一段可概括为"完成 A、记录 B、核对 C、确认 D"？
2. 是否有一场把来源、动作、结果、意义全部讲完？
3. 是否动作后又补一句解释效果或态度？
4. 是否同一数字被算了两次以上？
5. 是否把尚未确认的事写成了成果？
6. 是否只是用新物件替换旧解释，结构没变？
7. 章尾是否在总结人物学会了什么？
8. 小窗口内是否仍有独立的"出现→确认→执行→反馈"微闭环？

> 闲笔细节警告：AI 最会写"树荫挪了位置""红灯滑进队尾"式的闲笔与场景编排（实测往热窗加闲笔细节 0.71 反升 0.86）。细节必须挂在动作、摩擦、关系上，不挂在时间流逝与环境铺陈上。
